1. If \( f(x) = \dfrac{5x-6}{3} \), then \( f(3) = \) ?

✅ Correct Answer: (B) 3
Substitute \(x=3\): \( f(3) = \dfrac{5(3)-6}{3} = \dfrac{15-6}{3} = \dfrac{9}{3} = 3 \).

2. A function \( f \) from set \( X \) to set \( Y \) is represented as:

✅ Correct Answer: (C) \( f: X \to Y \)
The standard notation for a function from set \(X\) to set \(Y\) is \( f: X \to Y \).

3. \( (f \circ g)(x) \) equals:

✅ Correct Answer: (C) \( f(g(x)) \)
By definition, composition of functions \( (f \circ g)(x) = f(g(x)) \).

4. If \( f(x) = 2x+3 \) and \( g(x) = x+1 \), then \( f(x) + g(x) = \) ?

✅ Correct Answer: (B) \(3x+4\)
\( f(x)+g(x) = (2x+3)+(x+1) = 3x+4 \).

5. If \( f(x) = 5x+2 \) and \( h(x) = 2x-2 \), then \( f(x) - h(x) = \) ?

✅ Correct Answer: (C) \(3x+4\)
\( f(x)-h(x) = (5x+2)-(2x-2) = 5x+2-2x+2 = 3x+4 \).

6. If \( f(x) = 3x+1 \) and \( g(x) = 2x \), then \( g(x) \times f(x) = \) ?

✅ Correct Answer: (D) \(6x^2+2x\)
\( g(x) \times f(x) = 2x(3x+1) = 6x^2+2x \).

7. If \( f(x) = x^2-4 \) and \( g(x) = x+2 \) (with \( x \neq -2 \)), then \( \dfrac{f(x)}{g(x)} = \) ?

✅ Correct Answer: (D) \(x-2\)
\( \dfrac{x^2-4}{x+2} = \dfrac{(x-2)(x+2)}{x+2} = x-2 \), \( x \neq -2 \).

8. The graph of an absolute value function \( f(x) = |x| \) is:

✅ Correct Answer: (B) V-shaped
The absolute value function \(f(x)=|x|\) has a characteristic V-shaped graph with the vertex at the origin.

9. The vertical line test states that a graph represents a function if every vertical line intersects it at:

✅ Correct Answer: (D) 1 point
A graph represents a function if every vertical line intersects the graph at at most one point.

10. If \( f(x) = x^3 \), then \( f(-2) = \) ?

✅ Correct Answer: (A) \(-8\)
\( f(-2) = (-2)^3 = -8 \).

11. If \( f(x) = 3x+7 \), then \( f^{-1}(x) = \) ?

✅ Correct Answer: (B) \( \dfrac{x-7}{3} \)
Let \(y=3x+7\). Swap and solve: \(x=3y+7 \Rightarrow y=\dfrac{x-7}{3}\).

12. If \( |x| = 5 \), then the possible values of \( x \) are:

✅ Correct Answer: (C) \(5\) and \(-5\)
By definition, \( |x|=5 \) means \( x=5 \) or \( x=-5 \).

13. The vertex of the graph of \( f(x) = |x - 3| + 2 \) is at:

✅ Correct Answer: (A) \((3, 2)\)
For \( f(x)=|x-h|+k \), the vertex is at \((h,k)\). Here \(h=3\) and \(k=2\).

14. The domain of the function \( f(x) = \dfrac{1}{x-5} \) is all real numbers except:

✅ Correct Answer: (D) \(x = 5\)
The denominator cannot be zero. So \(x-5 \neq 0 \Rightarrow x \neq 5\).

15. If \( f(x) = x^2 \) and \( g(x) = x+1 \), then \( (f \circ g)(2) = \) ?

✅ Correct Answer: (B) \(9\)
\( (f \circ g)(2) = f(g(2)) = f(3) = 3^2 = 9 \).

16. Which of the following is the correct graph shape for \( y = -|x| \)?

✅ Correct Answer: (C) V-shaped opening downward
The negative sign reflects the graph of \(|x|\) over the x-axis, producing a downward-opening V.

17. If \( f(x) = 2x \) and \( g(x) = x+3 \), then \( f(g(1)) = \) ?

✅ Correct Answer: (A) \(8\)
\( g(1) = 1+3 = 4 \). Then \( f(4) = 2(4) = 8 \).

18. The solution of \( |2x - 4| = 6 \) is:

✅ Correct Answer: (B) \(x = 5\) or \(x = -1\)
\(2x-4=6 \Rightarrow x=5\); or \(2x-4=-6 \Rightarrow x=-1\).

19. If \( f(x) = x^2 \) and \( g(x) = x-3 \), then \( (g \circ f)(x) = \) ?

✅ Correct Answer: (D) \(x^2-3\)
\( (g \circ f)(x) = g(f(x)) = g(x^2) = x^2-3 \).

20. The solution set of \( |x - 2| \le 3 \) is:

✅ Correct Answer: (A) \([-1, 5]\)
\( |x-2| \le 3 \Rightarrow -3 \le x-2 \le 3 \Rightarrow -1 \le x \le 5 \).
