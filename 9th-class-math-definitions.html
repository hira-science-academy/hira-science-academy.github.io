Chapter 1 – Real Numbers

Rational and irrational numbers, decimal representation, operations

Updated 2027 ↓

Real numbers form the foundation of mathematics. This chapter covers rational and irrational numbers, decimal representation, and operations on real numbers.

Key Definitions & Theorems

  • Rational number: A number that can be written as \(\tfrac{p}{q}\), where \(p\) and \(q\) are integers and \(q \neq 0\).
  • Irrational number: A number that cannot be written as a simple fraction; its decimal form does not repeat or end.
  • Terminating decimal: A decimal that ends after a finite number of digits (e.g., \(0.25\)).
  • Recurring decimal: A decimal in which a digit or group of digits repeats without ending (e.g., \(0.333\ldots\)).
  • Additive inverse: The number that gives \(0\) when added to the original number (e.g., \(-5\) for \(5\)).
  • Multiplicative inverse: The number that gives \(1\) when multiplied by the original number (e.g., \(\tfrac{1}{5}\) for \(5\)).

Worked Example

Example 1: Show that \(0.333\ldots\) (recurring) is a rational number.

Let \(x = 0.333\ldots\). Then \(10x = 3.333\ldots\). Subtracting: \(9x = 3\), so \(x = \tfrac{1}{3}\). Since \(\tfrac{1}{3}\) is a fraction of two integers, \(0.333\ldots\) is rational.

Example 2: Simplify \(\sqrt{50}\). Answer: \(\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}\).

Chapter 2 – Logarithms

Laws of logarithms, common logarithms, exponential equations

Updated 2027↓

Logarithms help simplify complex calculations. This chapter covers laws, common logarithms, and applications in solving exponential equations.

Key Definitions & Theorems

  • Logarithm: If \(a^x = y\), then \(\log_a y = x\).
  • Common logarithm: A logarithm with base \(10\), written as \(\log x\).
  • Natural logarithm: A logarithm with base \(e\), written as \(\ln x\).
  • Product law: \(\log_a (mn) = \log_a m + \log_a n\)
  • Quotient law: \(\log_a \left(\tfrac{m}{n}\right) = \log_a m - \log_a n\)
  • Power law: \(\log_a (m^n) = n \log_a m\)

Worked Example

Example 1: Find \(\log_2 32\). Since \(2^5 = 32\), \(\log_2 32 = 5\).

Example 2: Solve \(\log x = 2.5\). Then \(x = 10^{2.5} \approx 316.23\).

Chapter 3 – Sets and Functions

Set operations, Venn diagrams, function types, notation

Updated 2027↓

Sets and functions are fundamental concepts in mathematics with applications in computer science and data analysis.

Key Definitions & Theorems

  • Set: A well-defined collection of distinct objects.
  • Subset: A set whose every element belongs to another set.
  • Union: \(A \cup B = \{x \mid x \in A \text{ or } x \in B\}\)
  • Intersection: \(A \cap B = \{x \mid x \in A \text{ and } x \in B\}\)
  • Function: A relation where each input has exactly one output.
  • Domain: The set of all possible inputs of a function.
  • Range: The set of all possible outputs of a function.

Worked Example

Example 1: If \(A = \{1, 2, 3\}\) and \(B = \{3, 4, 5\}\), find \(A \cup B\) and \(A \cap B\). \(A \cup B = \{1, 2, 3, 4, 5\}\); \(A \cap B = \{3\}\).

Example 2: If \(f(x) = 2x + 1\), find \(f(3)\). \(f(3) = 2(3) + 1 = 7\).

Chapter 4 – Factorization and Algebraic Manipulation

Factorization techniques, algebraic fractions, simplification

Updated 2027↓

Factorization simplifies algebraic expressions and equations. This chapter covers various factorization techniques and simplification.

Key Definitions & Theorems

  • Factorization: Writing an expression as a product of its factors.
  • Common factor: A factor shared by every term of an expression.
  • \(a^2 - b^2 = (a + b)(a - b)\)
  • \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\)
  • \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\)

Worked Example

Example 1: Factorize \(x^2 - 9\). \(x^2 - 9 = (x + 3)(x - 3)\).

Example 2: Factorize \(x^3 + 8\). \(x^3 + 8 = (x + 2)(x^2 - 2x + 4)\).

Chapter 5 – Linear Equations and Inequalities

Solving linear equations, graphing inequalities, word problems

Updated 2027↓

Linear equations and inequalities are essential for solving real-world problems in economics, physics, and engineering.

Key Definitions & Theorems

  • Linear equation: An equation of the form \(ax + b = 0\), where \(a \neq 0\).
  • Inequality: A statement that one quantity is greater or less than another (e.g., \(x > 5\)).
  • Solution set: All values that satisfy the equation or inequality.
  • Linear inequality: An inequality of the form \(ax + b < 0\), \(ax + b > 0\), and so on.

Worked Example

Example 1: Solve \(3x - 7 = 8\). \(3x = 15\), so \(x = 5\).

Example 2: Solve \(2x + 3 > 9\). \(2x > 6\), so \(x > 3\).

Chapter 6 – Trigonometry

Trigonometric ratios, identities, triangle solving, applications

Updated 2027↓

Trigonometry deals with relationships between angles and sides of triangles with applications in architecture and navigation.

Key Definitions & Theorems

  • \(\sin\theta = \dfrac{\text{perpendicular}}{\text{hypotenuse}}\)
  • \(\cos\theta = \dfrac{\text{base}}{\text{hypotenuse}}\)
  • \(\tan\theta = \dfrac{\text{perpendicular}}{\text{base}}\)
  • \(\sin^2\theta + \cos^2\theta = 1\)
  • \(1 + \tan^2\theta = \sec^2\theta\)

Worked Example

Example 1: In a right triangle, if \(\sin\theta = \tfrac{3}{5}\), find \(\cos\theta\). Using \(\sin^2\theta + \cos^2\theta = 1\), \(\cos\theta = \tfrac{4}{5}\).

Example 2: Find the value of \(\tan 45^\circ\). \(\tan 45^\circ = 1\).

Chapter 7 – Coordinate Geometry

Cartesian plane, distance formula, midpoint, line equations

Updated 2027↓

Coordinate geometry connects algebra and geometry with applications in computer graphics and engineering.

Key Definitions & Theorems

  • Cartesian plane: A plane formed by two perpendicular number lines called axes.
  • Distance formula: \(d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)
  • Midpoint formula: \(M = \left(\dfrac{x_1 + x_2}{2},\ \dfrac{y_1 + y_2}{2}\right)\)
  • Slope of a line: \(m = \dfrac{y_2 - y_1}{x_2 - x_1}\)

Worked Example

Example 1: Find the distance between \(A(1, 2)\) and \(B(4, 6)\). \(d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5\).

Example 2: Find the midpoint of \(A(1, 2)\) and \(B(4, 6)\). \(M = \left(\tfrac{1+4}{2}, \tfrac{2+6}{2}\right) = (2.5,\ 4)\).

Chapter 8 – Logic

Statements, truth tables, logical equivalence, proof techniques

Updated 2027↓

Logic forms the basis of mathematical reasoning and computer programming.

Key Definitions & Theorems

  • Statement: A sentence that is either true or false, but not both.
  • Negation: The opposite of a statement, written \(\sim p\).
  • Conjunction: \(p \land q\) (true only when both \(p\) and \(q\) are true).
  • Disjunction: \(p \lor q\) (true when at least one of \(p\) or \(q\) is true).
  • Truth table: A table showing all possible truth values of a statement.

Worked Example

Example 1: If \(p\) is true and \(q\) is false, find \(p \land q\). \(p \land q\) is false because \(q\) is false.

Example 2: If \(p\) is true and \(q\) is false, find \(p \lor q\). \(p \lor q\) is true because \(p\) is true.

Chapter 9 – Similar Figures

Similarity criteria, ratio of areas and volumes, geometry applications

Updated 2027↓

Similar figures have the same shape but different sizes with applications in map reading and scale models.

Key Definitions & Theorems

  • Similar figures: Figures with the same shape but not necessarily the same size.
  • Congruent figures: Figures with the same shape and the same size.
  • Ratio of areas: If sides are in ratio \(a : b\), areas are in ratio \(a^2 : b^2\).
  • Ratio of volumes: If sides are in ratio \(a : b\), volumes are in ratio \(a^3 : b^3\).

Worked Example

Example 1: Two triangles are similar with sides in ratio \(2:3\). If the area of the smaller is \(20\text{ cm}^2\), find the area of the larger. Area ratio = \(4:9\), so larger area = \(20 \times \tfrac{9}{4} = 45\text{ cm}^2\).

Example 2: If two cubes have sides in ratio \(1:2\), find the ratio of their volumes. Volume ratio = \(1^3 : 2^3 = 1:8\).

Chapter 10 – Graphs of Functions

Linear, quadratic functions, graphing techniques, interpretations

Updated 2027↓

Graphs provide visual representations of functions with applications in economics and science.

Key Definitions & Theorems

  • Linear function: \(f(x) = mx + c\); its graph is a straight line.
  • Quadratic function: \(f(x) = ax^2 + bx + c\); its graph is a parabola.
  • Vertex: The turning point of a parabola.
  • Intercept: The point where a graph crosses an axis.

Worked Example

Example 1: Graph \(f(x) = 2x + 1\). Plot points \((0,1)\), \((1,3)\), \((2,5)\) and draw a straight line.

Example 2: Graph \(f(x) = x^2\). Plot points \((0,0)\), \((1,1)\), \((2,4)\), \((-1,1)\), \((-2,4)\) and draw a parabola.

Chapter 11 – Loci and Construction

Geometric constructions, loci problems, engineering applications

Updated 2027↓

Loci are sets of points satisfying specific conditions with applications in engineering design.

Key Definitions & Theorems

  • Locus: A set of points that satisfy a given condition.
  • Locus of points equidistant from a point: A circle.
  • Locus of points equidistant from two points: The perpendicular bisector of the line segment.

Worked Example

Example 1: Construct the locus of points equidistant from two given points \(A\) and \(B\). Draw the perpendicular bisector of \(AB\).

Example 2: Construct the locus of points at a distance of \(3\text{ cm}\) from a fixed point \(O\). Draw a circle with center \(O\) and radius \(3\text{ cm}\).

Chapter 12 – Information Handling

Data collection, graphical representations, statistical analysis

Updated 2027↓

Information handling is crucial in data analysis and decision making.

Key Definitions & Theorems

  • Mean: Sum of all values divided by the number of values.
  • Median: The middle value when data is arranged in order.
  • Mode: The value that appears most frequently.
  • Frequency: The number of times a value occurs.

Worked Example

Example 1: Find the mean of \(4, 8, 6, 10, 12\). Mean \(= \dfrac{4+8+6+10+12}{5} = \dfrac{40}{5} = 8\).

Example 2: Find the median of \(3, 5, 7, 9, 11\). Median \(= 7\) (middle value).

Chapter 13 – Probability

Basic concepts, sample spaces, probability calculation, applications

Updated 2027↓

Probability quantifies uncertainty in scientific research and finance.

Key Definitions & Theorems

  • Probability: \(P(E) = \dfrac{\text{number of favourable outcomes}}{\text{total number of possible outcomes}}\)
  • Sample space: The set of all possible outcomes.
  • Event: A subset of the sample space.
  • Complement: \(P(\text{not } E) = 1 - P(E)\).

Worked Example

Example 1: A fair die is rolled. Find the probability of getting an even number. Favorable outcomes: \(2, 4, 6\). \(P(\text{even}) = \tfrac{3}{6} = \tfrac{1}{2}\).

Example 2: A coin is tossed. Find the probability of getting heads. \(P(\text{heads}) = \tfrac{1}{2}\).
