Chapter 1 – Real Numbers

Rational and irrational numbers, decimal representation, operations

Updated 2027↓

Real numbers form the foundation of mathematics. This chapter covers rational and irrational numbers, decimal representation, and operations on real numbers.

Key Formulas

  • Every rational number can be written as \(\tfrac{p}{q}\) with \(q \neq 0\).
  • \(\sqrt{ab} = \sqrt{a}\sqrt{b}\) (for \(a, b \geq 0\)).
  • \(\sqrt{\tfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\) (for \(a \geq 0,\ b > 0\)).
  • Additive inverse of \(a\) is \(-a\); multiplicative inverse of \(a \neq 0\) is \(\tfrac{1}{a}\).

Worked Example

Example 1: Simplify \(\sqrt{50}\). \(\sqrt{50} = \sqrt{25\times 2} = 5\sqrt{2}\).

Example 2: Show \(0.333\ldots\) is rational. Let \(x = 0.333\ldots\); \(10x - x = 3\), so \(x = \tfrac{1}{3}\).

Chapter 2 – Logarithms

Laws of logarithms, common logarithms, exponential equations

Updated 2027↓

Logarithms help simplify complex calculations. This chapter covers laws, common logarithms, and applications in solving exponential equations.

Key Formulas

  • Definition: if \(a^x = y\), then \(\log_a y = x\).
  • Product law: \(\log_a(mn) = \log_a m + \log_a n\)
  • Quotient law: \(\log_a\!\left(\tfrac{m}{n}\right) = \log_a m - \log_a n\)
  • Power law: \(\log_a(m^n) = n \log_a m\)
  • Change of base: \(\log_a b = \dfrac{\log_c b}{\log_c a}\)

Worked Example

Example 1: Find \(\log_2 32\). Since \(2^5 = 32\), \(\log_2 32 = 5\).

Example 2: Solve \(\log x = 2.5\). Then \(x = 10^{2.5} \approx 316.23\).

Chapter 3 – Sets and Functions

Set operations, Venn diagrams, function types, notation

Updated 2027↓

Sets and functions are fundamental concepts in mathematics with applications in computer science and data analysis.

Key Formulas

  • Union: \(A \cup B = \{x \mid x \in A \text{ or } x \in B\}\)
  • Intersection: \(A \cap B = \{x \mid x \in A \text{ and } x \in B\}\)
  • \(n(A \cup B) = n(A) + n(B) - n(A \cap B)\)
  • Complement: \(A' = \{x \mid x \in U \text{ and } x \notin A\}\)

Worked Example

Example 1: \(A=\{1,2,3\}\), \(B=\{3,4,5\}\Rightarrow A \cup B=\{1,2,3,4,5\}\), \(A \cap B=\{3\}\).

Example 2: If \(f(x)=2x+1\), then \(f(3)=7\).

Chapter 4 – Factorization and Algebraic Manipulation

Factorization techniques, algebraic fractions, simplification

Updated 2027↓

Factorization simplifies algebraic expressions and equations. This chapter covers various factorization techniques and simplification.

Key Formulas

  • \((a + b)^2 = a^2 + 2ab + b^2\)
  • \((a - b)^2 = a^2 - 2ab + b^2\)
  • \(a^2 - b^2 = (a + b)(a - b)\)
  • \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\)
  • \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\)

Worked Example

Example 1: \(x^2 - 9 = (x + 3)(x - 3)\).

Example 2: \(x^3 + 8 = (x + 2)(x^2 - 2x + 4)\).

Chapter 5 – Linear Equations and Inequalities

Solving linear equations, graphing inequalities, word problems

Updated 2027↓

Linear equations and inequalities are essential for solving real-world problems in economics, physics, and engineering.

Key Formulas

  • Linear equation in one variable: \(ax + b = 0 \Rightarrow x = -\dfrac{b}{a}\)
  • Linear equation in two variables: \(ax + by + c = 0\)
  • If \(a < b\), then \(a + c < b + c\).
  • If \(a < b\) and \(c < 0\), then \(ac > bc\).

Worked Example

Example 1: \(3x - 7 = 8 \Rightarrow x = 5\).

Example 2: \(2x + 3 > 9 \Rightarrow x > 3\).

Chapter 6 – Trigonometry

Trigonometric ratios, identities, triangle solving, applications

Updated 2027↓

Trigonometry deals with relationships between angles and sides of triangles with applications in architecture and navigation.

Key Formulas

  • \(\sin\theta = \dfrac{\text{perpendicular}}{\text{hypotenuse}},\ \cos\theta = \dfrac{\text{base}}{\text{hypotenuse}},\ \tan\theta = \dfrac{\text{perpendicular}}{\text{base}}\)
  • \(\sin^2\theta + \cos^2\theta = 1\)
  • \(1 + \tan^2\theta = \sec^2\theta\)
  • \(1 + \cot^2\theta = \csc^2\theta\)
  • \(\sin 30^\circ = \tfrac{1}{2},\ \cos 60^\circ = \tfrac{1}{2},\ \tan 45^\circ = 1\)

Worked Example

Example 1: If \(\sin\theta = \tfrac{3}{5}\), then \(\cos\theta = \tfrac{4}{5}\).

Example 2: \(\tan 45^\circ = 1\).

Chapter 7 – Coordinate Geometry

Cartesian plane, distance formula, midpoint, line equations

Updated 2027↓

Coordinate geometry connects algebra and geometry with applications in computer graphics and engineering.

Key Formulas

  • Distance: \(d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)
  • Midpoint: \(M = \left(\dfrac{x_1 + x_2}{2},\ \dfrac{y_1 + y_2}{2}\right)\)
  • Slope: \(m = \dfrac{y_2 - y_1}{x_2 - x_1}\)
  • Equation of a line: \(y - y_1 = m(x - x_1)\)

Worked Example

Example 1: Distance between \(A(1,2)\) and \(B(4,6)\): \(d=\sqrt{9+16}=5\).

Example 2: Midpoint \(M = (2.5, 4)\).

Chapter 8 – Logic

Statements, truth tables, logical equivalence, proof techniques

Updated 2027↓

Logic forms the basis of mathematical reasoning and computer programming.

Key Formulas

  • \(\sim p\) is true when \(p\) is false.
  • \(p \land q\) true only when both \(p\) and \(q\) are true.
  • \(p \lor q\) true when at least one is true.
  • De Morgan: \(\sim(p \land q) \equiv \sim p \lor \sim q\); \(\sim(p \lor q) \equiv \sim p \land \sim q\).

Worked Example

Example 1: If \(p\) true and \(q\) false, \(p \land q\) is false.

Example 2: If \(p\) true and \(q\) false, \(p \lor q\) is true.

Chapter 9 – Similar Figures

Similarity criteria, ratio of areas and volumes, geometry applications

Updated 2027↓

Similar figures have the same shape but different sizes with applications in map reading and scale models.

Key Formulas

  • Sides of similar figures: \(a : b\)
  • Perimeters: \(a : b\)
  • Areas: \(a^2 : b^2\)
  • Volumes: \(a^3 : b^3\)

Worked Example

Example 1: Sides \(2:3\); smaller area \(20\text{ cm}^2\); larger area \(=20\times \tfrac{9}{4}=45\text{ cm}^2\).

Example 2: Cubes \(1:2\) sides \(\Rightarrow\) volumes \(1:8\).

Chapter 10 – Graphs of Functions

Linear, quadratic functions, graphing techniques, interpretations

Updated 2027↓

Graphs provide visual representations of functions with applications in economics and science.

Key Formulas

Chapter 11 – Loci and Construction

Geometric constructions, loci problems, engineering applications

Updated 2027↓

Loci are sets of points satisfying specific conditions with applications in engineering design.

Key Formulas

  • Locus at fixed distance \(r\) from a point: circle of radius \(r\).
  • Locus equidistant from two points: perpendicular bisector.
  • Locus equidistant from two intersecting lines: angle bisectors.

Worked Example

Example 1: Draw perpendicular bisector of \(AB\).

Example 2: Circle of radius \(3\text{ cm}\) about \(O\).

Chapter 12 – Information Handling

Data collection, graphical representations, statistical analysis

Updated 2027↓

Information handling is crucial in data analysis and decision making.

Key Formulas

  • Mean: \(\bar{x} = \dfrac{\sum x_i}{n}\)
  • Median: middle value of ordered data.
  • Mode: most frequent value.
  • Range: \(\text{max} - \text{min}\)

Worked Example

Example 1: Mean of \(4,8,6,10,12\) is \(8\).

Example 2: Median of \(3,5,7,9,11\) is \(7\).

Chapter 13 – Probability

Basic concepts, sample spaces, probability calculation, applications

Updated 2027↓

Probability quantifies uncertainty in scientific research and finance.

Key Formulas

  • \(P(E) = \dfrac{\text{number of favourable outcomes}}{\text{total number of possible outcomes}}\)
  • \(0 \leq P(E) \leq 1\)
  • \(P(\text{not } E) = 1 - P(E)\)

Worked Example

Example 1: Die rolled; \(P(\text{even}) = \tfrac{3}{6} = \tfrac{1}{2}\).

Example 2: Coin tossed; \(P(\text{heads}) = \tfrac{1}{2}\).

Why a Good Formula Sheet Is More Than a Memory Aid

Formulas are the shortcuts mathematics gives us — compact rules that replace pages of derivation with a single line you can apply directly. But with 13 chapters of Class 9 Mathematics, each carrying its own set of formulas, keeping track of all of them without a central reference becomes its own challenge. That's exactly what this formula sheet is built to solve.

This page organizes every important formula from the Punjab Board 2027 syllabus chapter by chapter, so you're never digging through pages of notes to find the one you need. Chapters like Logarithms, Trigonometry, and Coordinate Geometry are particularly formula-dense, and having them consolidated in one place saves real time, both while solving exercises and during final revision.

A formula sheet works best when it's used as a quick-reference tool, not a substitute for understanding. Knowing \(\log_a(mn) = \log_a m + \log_a n\) by heart is only half the job — recognizing which situation calls for it, and why it works, is what actually earns marks on a board exam. Use this sheet to confirm you're recalling a formula correctly, then go back to the relevant chapter's solved exercises to practice applying it.

Some chapters, like Coordinate Geometry, involve several closely related formulas — \(d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\), \(M = \left(\tfrac{x_1+x_2}{2}, \tfrac{y_1+y_2}{2}\right)\), and \(m = \tfrac{y_2-y_1}{x_2-x_1}\), for example — that are easy to mix up under exam pressure. Reviewing them side by side, as they're organized here, helps you notice the small but important differences between them before that confusion costs you marks.

Formula recall speed matters especially for MCQs and short questions, where there isn't time to re-derive a result from first principles. Regularly reviewing this sheet — not just once before an exam, but in short sessions throughout your revision period — builds the kind of instant recall that keeps your working time focused on the actual problem rather than searching your memory.

This resource is useful for teachers creating quick-reference handouts, and for parents who want a simple way to quiz their child on formula recall. Since it's built around the 2027 Punjab Board syllabus shared by all 10 BISE boards in Punjab — Bahawalpur, DG Khan, Faisalabad, Federal, Gujranwala, Lahore, Multan, Rawalpindi, Sahiwal, and Sargodha — it applies no matter which board a student is registered under.

Open any chapter above to review its formulas. Once you're confident recalling them, the solved exercises and important questions linked further down this page are the best way to practice applying each one correctly.

💡 Revision Tips for Formulas

  • • Group by chapter: Revise formulas from one chapter at a time to avoid mixing them up.
  • • Write them out by hand: Writing a formula from memory cements it better than just reading it.
  • • Compare similar formulas: Review related formulas side by side, like distance and midpoint, to avoid confusion.
  • • Keep a printed copy handy: A physical formula sheet is useful for quick glances while practicing.
  • • Revise in short, frequent sessions: A few minutes daily builds recall better than one long cram.

🎯 Applying Formulas Correctly in Exams

  • • Identify the right formula first: Before writing anything, confirm which formula the question actually needs.
  • • Show the formula in your working: Writing the formula before substitution earns method marks.
  • • Double-check units and signs: A correct formula with a sign error still leads to a wrong answer.
  • • Practice with solved exercises: Apply each formula in context, not just in isolation.
  • • Test recall speed with MCQs: Use our MCQs test above to check how quickly you can identify the right formula.

⚠️ Common Formula Mistakes

  • • Mixing up similar formulas: Especially common in Coordinate Geometry and Trigonometry.
  • • Using a formula without checking conditions: Some formulas only apply under specific conditions.
  • • Forgetting to show the formula in working: Jumping straight to numbers can cost method marks.
  • • Sign errors during substitution: A dropped negative sign can invalidate an otherwise correct formula.

🧠 Building Stronger Formula Recall

  • • Connect formulas to their derivations: Knowing where a formula comes from makes it easier to remember.
  • • Practice recall without looking: Try writing a chapter's formulas from memory, then check against this sheet.
  • • Apply, don't just memorize: Use each formula in a solved exercise to reinforce it in context.
  • • Revisit weak chapters often: Formulas you forget quickly need more frequent review than ones you know well.
