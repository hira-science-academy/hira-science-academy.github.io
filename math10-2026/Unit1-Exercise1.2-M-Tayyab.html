📖 Exercise 1.2 – Step-by-Step Solutions (As per PDF)

1 Simplify and write in the form \(a + b\iota\):
(i) \((2 + 5\iota) + (3 - 2\iota) = 2+5\iota+3-2\iota = 5 + 3\iota\)
(ii) \((16 - 3\iota) + (9 + 2\iota) = 16-3\iota+9+2\iota = 25 - \iota\)
(iii) \((9 - 2\iota) - (7 - 3\iota) = 9-2\iota-7+3\iota = 2 + \iota\)
(iv) \((11 + 9\iota) - (9 - 7\iota) = 11+9\iota-9+7\iota = 2 + 16\iota\)
(v) \((3 + 4\iota)(2 - 3\iota) = 3(2-3\iota)+4\iota(2-3\iota)=6-9\iota+8\iota-12\iota^2 = 6 - \iota -12(-1)=18 - \iota\)
(vi) \((5 - 2\iota)(3 - 4\iota) = 5(3-4\iota)-2\iota(3-4\iota)=15-20\iota-6\iota+8\iota^2 = 15-26\iota+8(-1)=7 - 26\iota\)
(vii) \((3 - 5\iota) \div (2 - 4\iota) = \frac{3-5\iota}{2-4\iota} \times \frac{2+4\iota}{2+4\iota} = \frac{6+12\iota-10\iota-20\iota^2}{4-16\iota^2} = \frac{6+2\iota+20}{4+16} = \frac{26+2\iota}{20} = \frac{13}{10} + \frac{1}{10}\iota\)
(viii) \((5 + 2\iota) \div (6 - 3\iota) = \frac{5+2\iota}{6-3\iota} \times \frac{6+3\iota}{6+3\iota} = \frac{30+15\iota+12\iota+6\iota^2}{36-9\iota^2} = \frac{30+27\iota-6}{36+9} = \frac{24+27\iota}{45} = \frac{8}{15} + \frac{3}{5}\iota\)
2 Write additive inverse for each complex number:
(i) \(3 + 2\iota\) : Additive inverse is \(-3 - 2\iota\)
(ii) \(4 - 3\iota\) : Additive inverse is \(-4 + 3\iota\)
(iii) \(5 - 7\iota\) : Additive inverse is \(-5 + 7\iota\)
(iv) \(-\frac{2}{3} + \frac{5}{4}\iota\) : Additive inverse is \(\frac{2}{3} - \frac{5}{4}\iota\)
3 Find multiplicative inverse for each complex number:
(i) \(4 + 5\iota\) : \(z^{-1} = \frac{1}{4+5\iota} \times \frac{4-5\iota}{4-5\iota} = \frac{4-5\iota}{16-25\iota^2} = \frac{4-5\iota}{16+25} = \frac{4}{41} - \frac{5}{41}\iota\)
(ii) \(6 + 2\iota\) : \(z^{-1} = \frac{1}{6+2\iota} \times \frac{6-2\iota}{6-2\iota} = \frac{6-2\iota}{36-4\iota^2} = \frac{6-2\iota}{36+4} = \frac{6-2\iota}{40} = \frac{3}{20} - \frac{1}{20}\iota\)
(iii) \(7 - 3\iota\) : \(z^{-1} = \frac{1}{7-3\iota} \times \frac{7+3\iota}{7+3\iota} = \frac{7+3\iota}{49-9\iota^2} = \frac{7+3\iota}{49+9} = \frac{7}{58} + \frac{3}{58}\iota\)
(iv) \(\sqrt{5} - 4\iota\) : \(z^{-1} = \frac{1}{\sqrt{5}-4\iota} \times \frac{\sqrt{5}+4\iota}{\sqrt{5}+4\iota} = \frac{\sqrt{5}+4\iota}{5-16\iota^2} = \frac{\sqrt{5}+4\iota}{5+16} = \frac{\sqrt{5}}{21} + \frac{4}{21}\iota\)
4 If \(z_1=2+5\iota,\; z_2=1-3\iota,\; z_3=2+\iota\), then verify that:
(i) \(z_1+z_2 = z_2+z_1\)
LHS = \((2+5\iota)+(1-3\iota)=3+2\iota\)
RHS = \((1-3\iota)+(2+5\iota)=3+2\iota\) ✓
(ii) \(z_1z_2 = z_2z_1\)
LHS = \((2+5\iota)(1-3\iota)=17-\iota\)
RHS = \((1-3\iota)(2+5\iota)=17-\iota\) ✓
(iii) \((z_1+z_2)+z_3 = z_1+(z_2+z_3)\)
LHS = \( (3+2\iota)+(2+\iota)=5+3\iota\)
RHS = \((2+5\iota)+(3-2\iota)=5+3\iota\) ✓
(iv) \((z_1z_2)z_3 = z_1(z_2z_3)\)
\(z_1z_2=17-\iota\), then \((17-\iota)(2+\iota)=35+15\iota\)
\(z_2z_3=(1-3\iota)(2+\iota)=5-5\iota\), then \((2+5\iota)(5-5\iota)=35+15\iota\) ✓
(v) \(z_1+(-z_1)=(-z_1)+z_1=0\)
\(-z_1 = -2-5\iota\) ⇒ \((2+5\iota)+(-2-5\iota)=0\) ✓
5 If \(\frac{(1+\iota)^2}{2-\iota}=x+\iota y\), find \(x\) and \(y\).
\((1+\iota)^2 = 1 + 2\iota + \iota^2 = 1+2\iota-1 = 2\iota\)
\(\frac{2\iota}{2-\iota} \times \frac{2+\iota}{2+\iota} = \frac{4\iota+2\iota^2}{4-\iota^2} = \frac{4\iota-2}{4+1} = \frac{-2+4\iota}{5} = -\frac{2}{5} + \frac{4}{5}\iota\)
Thus \(x = -\frac{2}{5},\; y = \frac{4}{5}\).
6 If \((2x+\iota y)(1-\iota)=4+2\iota\), find \(x\) and \(y\).
\((2x+\iota y)(1-\iota)=4+2\iota \Rightarrow 2x+\iota y = \frac{4+2\iota}{1-\iota}\)
\(\frac{4+2\iota}{1-\iota} \times \frac{1+\iota}{1+\iota} = \frac{4(1+\iota)+2\iota(1+\iota)}{1+1} = \frac{4+4\iota+2\iota+2\iota^2}{2} = \frac{4+6\iota-2}{2} = \frac{2+6\iota}{2} = 1+3\iota\)
Equating real and imaginary parts: \(2x=1 \Rightarrow x=\frac{1}{2},\; y=3\).
7 Find the values of \(a\) and \(b\), if \(\frac{3+\iota}{2-\iota} \cdot \frac{5+\iota}{3-2\iota} = a + b\iota\).
First: \(\frac{3+\iota}{2-\iota} = \frac{(3+\iota)(2+\iota)}{(2-\iota)(2+\iota)} = \frac{6+3\iota+2\iota+\iota^2}{4+1} = \frac{5+5\iota}{5} = 1+\iota\)
Second: \(\frac{5+\iota}{3-2\iota} = \frac{(5+\iota)(3+2\iota)}{(3-2\iota)(3+2\iota)} = \frac{15+10\iota+3\iota+2\iota^2}{9+4} = \frac{13+13\iota}{13} = 1+\iota\)
Product: \((1+\iota)(1+\iota) = 1 + 2\iota + \iota^2 = 2\iota = 0 + 2\iota\)
Hence \(a = 0,\; b = 2\).

📐 Key Formulas – Complex Numbers

Additive Inverse: \(-(a+b\iota) = -a - b\iota\)
Multiplicative Inverse: \(\frac{1}{a+b\iota} = \frac{a-b\iota}{a^2+b^2}\)
Conjugate Multiplication: \((a+b\iota)(a-b\iota)=a^2+b^2\)

💡 Exam Tip:

For division of complex numbers, always multiply numerator and denominator by the conjugate of the denominator. These solutions follow the PECTAA 2026 pattern and are prepared by Subject Specialist Muhammad Tayyab.
