Chapter 1: Real Numbers

Rational and irrational numbers, decimal representation, operations

Real numbers are the base for everything that follows in algebra. You learn how to tell rational from irrational numbers, how recurring decimals convert to fractions, and how to simplify radicals.

Key formulas and rules

  • Rational number: pq where p, q are integers and q ≠ 0.
  • Irrational number: cannot be written as a fraction; its decimal neither ends nor repeats.
  • Inverses: additive inverse of a is −a; multiplicative inverse is 1a for a ≠ 0.
  • √ab = √a · √b for a, b ≥ 0.

Worked examples

Example 1. Show that 0.333… is rational. Let x = 0.333…. Then 10x − x = 3, so 9x = 3 and x = 13.

Example 2. Simplify √50: √50 = √25 × 2 = 5√2.

Common mistake. √a + b is not the same as √a + √b. The root splits over multiplication only.

Chapter 2: Logarithms

Laws of logarithms, common logarithms, exponential equations

Logarithms turn multiplication into addition. This chapter covers the three laws, common (base 10) logarithms and their use in solving exponential equations.

Key formulas and rules

  • Definition: if ax = y then loga y = x.
  • loga(mn) = loga m + loga n
  • loga(mn) = loga m − loga n
  • loga(mn) = n loga m

Worked examples

Example 1. log2 32 = 5 because 25 = 32.

Example 2. Solve log x = 2.5: x = 102.5 ≈ 316.23.

Common mistake. log(m + n) does not split into log m + log n. The product law needs m × n inside the log.

Chapter 3: Sets and Functions

Set operations, Venn diagrams, function types, notation

Sets give you the language to group objects and functions give you rules to map one set to another. Venn diagrams and set notation appear in both MCQs and long questions.

Key formulas and rules

  • Set: a well-defined collection of distinct objects.
  • A ∪ B = {x | x ∈ A or x ∈ B}
  • A ∩ B = {x | x ∈ A and x ∈ B}
  • n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

Worked examples

Example 1. A = {1, 2, 3}, B = {3, 4, 5} gives A ∪ B = {1, 2, 3, 4, 5} and A ∩ B = {3}.

Example 2. If f(x) = 2x + 1 then f(3) = 7.

Common mistake. In n(A ∪ B) subtract n(A ∩ B), or the common elements are counted twice.

Chapter 4: Factorization and Algebraic Manipulation

Factorization techniques, algebraic fractions, simplification

Factorization is the most reused skill in Class 9 algebra. Learn the standard identities well and most questions in this chapter become pattern matching.

Key formulas and rules

  • (a + b)2 = a2 + 2ab + b2
  • (a − b)2 = a2 − 2ab + b2
  • a2 − b2 = (a + b)(a − b)
  • a3 ± b3 = (a ± b)(a2 ∓ ab + b2)

Worked examples

Example 1. x2 − 9 = (x + 3)(x − 3)

Example 2. x3 + 8 = (x + 2)(x2 − 2x + 4)

Common mistake. (a + b)2 is not a2 + b2. The middle term 2ab is the one students forget.

Chapter 5: Linear Equations and Inequalities

Solving linear equations, graphing inequalities, word problems

Linear equations and inequalities model real situations in money, speed and measurement. The key skill is turning a word problem into an equation and solving it cleanly.

Key formulas and rules

  • ax + b = 0 ⇒ x = −ba
  • ax + by + c = 0 is a linear equation in two variables.
  • If a < b then a + c < b + c. If c < 0 then ac > bc.

Worked examples

Example 1. 3x − 7 = 8 ⇒ x = 5

Example 2. 2x + 3 > 9 ⇒ x > 3

Common mistake. Multiplying or dividing both sides of an inequality by a negative number reverses the sign.

Chapter 6: Trigonometry

Trigonometric ratios, identities, triangle solving, applications

Trigonometry links angles to side lengths in a right-angled triangle. Master the three basic ratios and the two identities, and heights-and-distances problems follow easily.

Key formulas and rules

  • sin θ = perpendicularhypotenuse, cos θ = basehypotenuse, tan θ = perpendicularbase
  • sin2θ + cos2θ = 1
  • 1 + tan2θ = sec2θ

Worked examples

Example 1. If sin θ = 35 then cos θ = 45.

Example 2. tan 45° = 1

Common mistake. sin2θ means (sin θ)2. Name the perpendicular and base from the angle you are using, not from the picture.

Chapter 7: Coordinate Geometry

Cartesian plane, distance formula, midpoint, line equations

Coordinate geometry puts algebra on the plane. Distance, midpoint and slope are three short formulas that solve most questions in this chapter.

Key formulas and rules

  • Distance: d = √(x2 − x1)2 + (y2 − y1)2
  • Midpoint: M = (x1 + x22, y1 + y22)
  • Slope: m = y2 − y1x2 − x1
  • Line: y − y1 = m(x − x1)

Worked examples

Example 1. A(1, 2), B(4, 6): d = √9 + 16 = 5.

Example 2. Midpoint of A and B is (2.5, 4).

Common mistake. Subtract coordinates in the same order for x and y, and write slope as change in y over change in x.

Chapter 8: Logic

Statements, truth tables, logical equivalence, proof techniques

Logic is the grammar of mathematical reasoning. You work with statements, connectives and truth tables, and check when two statements are equivalent.

Key formulas and rules

  • Statement: a sentence that is either true or false, but not both.
  • ~(p ∧ q) ≡ ~p ∨ ~q
  • ~(p ∨ q) ≡ ~p ∧ ~q

Worked examples

Example 1. p true and q false gives p ∧ q false.

Example 2. p true and q false gives p ∨ q true.

Common mistake. Questions and commands are not statements, because they cannot be called true or false.

Chapter 9: Similar Figures

Similarity criteria, ratio of areas and volumes, geometry applications

Similar figures have the same shape but different size. The chapter is about how lengths, areas and volumes scale, which is also what map reading and scale models use.

Key formulas and rules

  • Sides of similar figures are in the ratio a : b.
  • Areas are in the ratio a2 : b2.
  • Volumes are in the ratio a3 : b3.

Worked examples

Example 1. Sides 2 : 3, smaller area 20 cm2: larger area = 20 × 94 = 45 cm2.

Example 2. Cubes with sides 1 : 2 have volumes 1 : 8.

Common mistake. Use the square of the side ratio for areas and the cube for volumes. Using the side ratio directly is the usual error.

Chapter 10: Graphs of Functions

Linear and quadratic functions, graphing techniques, interpretation

Graphs turn a formula into a picture. You plot linear and quadratic functions from a table of values and read information such as slope and turning point from the curve.

Key formulas and rules

  • Linear: f(x) = mx + c
  • Quadratic: f(x) = ax2 + bx + c
  • Vertex x-coordinate: x = −b2a

Worked examples

Example 1. Graph f(x) = 2x + 1 using the points (0, 1), (1, 3), (2, 5).

Example 2. Graph f(x) = x2 using (0, 0), (±1, 1), (±2, 4).

Common mistake. For a parabola, plot at least five points and join them with a smooth curve, not straight segments.

Chapter 11: Loci and Construction

Geometric constructions, loci problems, engineering applications

A locus is the path of a point that follows a rule. This chapter is practical: you construct bisectors and loci with a ruler and compass.

Key formulas and rules

  • Points at distance r from a fixed point form a circle of radius r.
  • Points equidistant from two points lie on their perpendicular bisector.
  • Points equidistant from two intersecting lines lie on their angle bisectors.

Worked examples

Example 1. Draw the perpendicular bisector of AB.

Example 2. Draw the circle of radius 3 cm about O.

Common mistake. Keep the compass width fixed while drawing a pair of arcs, and leave the construction arcs visible for marks.

Chapter 12: Information Handling

Data collection, graphical representation, statistical analysis

Information handling is about collecting data and summarising it with averages and graphs. Mean, median and mode are the core of the chapter.

Key formulas and rules

  • Mean: x̄ = ∑xin
  • Median: the middle value of the ordered data.
  • Mode: the most frequent value.

Worked examples

Example 1. Mean of 4, 8, 6, 10, 12 is 8.

Example 2. Median of 3, 5, 7, 9, 11 is 7.

Common mistake. Arrange the data in order before looking for the median.

Chapter 13: Probability

Basic concepts, sample space, calculating probability, applications

Probability measures how likely an event is. You list the sample space, count favourable outcomes and use the simple ratio formula.

Key formulas and rules

  • P(E) = number of favourable outcomestotal number of possible outcomes
  • 0 ≤ P(E) ≤ 1
  • P(not E) = 1 − P(E)

Worked examples

Example 1. A die is rolled: P(even) = 36 = 12.

Example 2. A coin is tossed: P(heads) = 12.

Common mistake. A probability can never be negative or above 1. If you get 1.2, recount the outcomes.

In the exam hall

  • Read each question twice and underline the given data.
  • Show every step. Marks are given for method, not only the answer.
  • Draw a neat figure for geometry, loci and trigonometry questions.
  • Put the answer back into the equation to check it.
  • Keep a few minutes at the end to revise.

Before the exam

  • Revise definitions and formulas every day, a few at a time.
  • Solve at least five years of past papers.
  • Use the formula sheet and definitions page for quick revision.
  • Practise MCQs by chapter, then take the full online test.
