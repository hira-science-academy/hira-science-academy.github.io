📘 Chapter 1 – Real Numbers

➕

Key Concepts: This chapter explains the number system, dividing numbers into rational and irrational. It covers properties of real numbers, representation on the number line, and operations with radicals.

Important Formulas:
• \(\sqrt{ab} = \sqrt{a} \times \sqrt{b}\)
• \(\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\)
• \((a + b)(a - b) = a^2 - b^2\)
• Rationalizing denominator: \(\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}\)
Properties of Real Numbers:
• Commutative: \(a + b = b + a\); \(a \times b = b \times a\)
• Associative: \((a + b) + c = a + (b + c)\)
• Distributive: \(a \times (b + c) = a \times b + a \times c\)
• Additive Identity: \(a + 0 = a\)
• Multiplicative Identity: \(a \times 1 = a\)

📗 Chapter 2 – Logarithms

➕

Key Concepts: This chapter introduces logarithms as the inverse of exponents. It covers the fundamental laws of logarithms, common logarithms (base 10), and their applications in simplifying calculations. The relationship between exponents and logarithms is explored through various examples and problems.

Laws of Logarithms:
• \(\log_a(mn) = \log_a m + \log_a n\)
• \(\log_a\left(\frac{m}{n}\right) = \log_a m - \log_a n\)
• \(\log_a(m^n) = n \log_a m\)
• \(\log_a a = 1\)
• \(\log_a 1 = 0\)
• Change of Base: \(\log_a b = \frac{\log_n b}{\log_n a}\)

📙 Chapter 3 – Sets and Functions

➕

Key Concepts: This chapter introduces fundamental concepts of sets and functions. It covers set operations (union, intersection, difference), types of sets (finite, infinite, equal, equivalent), and various types of functions (linear, quadratic, constant). Venn diagrams are used extensively to visualize set relationships.

Set Operations:
• \(A \cup B = \{x \mid x \in A \text{ or } x \in B\}\)
• \(A \cap B = \{x \mid x \in A \text{ and } x \in B\}\)
• \(A - B = \{x \mid x \in A \text{ and } x \notin B\}\)
• \(A' = \{x \mid x \notin A\}\)
• \(n(A \cup B) = n(A) + n(B) - n(A \cap B)\)

📕 Chapter 4 – Factorization and Algebraic Manipulation

➕

Key Concepts: This chapter covers various techniques for factorizing algebraic expressions including common factors, grouping, difference of squares, perfect squares, and sum/difference of cubes. It also includes algebraic manipulation techniques such as simplification of complex fractions and rational expressions.

Factorization Formulas:
• \(a^2 - b^2 = (a - b)(a + b)\)
• \(a^2 \pm 2ab + b^2 = (a \pm b)^2\)
• \(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\)
• \(x^2 + (a + b)x + ab = (x + a)(x + b)\)
• \(acx^2 + (ad + bc)x + bd = (ax + b)(cx + d)\)

📒 Chapter 6 – Trigonometry

➕

Key Concepts: This chapter introduces trigonometric ratios (sine, cosine, tangent) for acute angles in right-angled triangles. It covers fundamental trigonometric identities, applications to solve right triangles, and angle measurement in degrees. The chapter also includes practical applications of trigonometry in real-world problems.

Trigonometric Ratios:
• \(\sin\theta = \frac{\text{Opposite}}{\text{Hypotenuse}}\)
• \(\cos\theta = \frac{\text{Adjacent}}{\text{Hypotenuse}}\)
• \(\tan\theta = \frac{\text{Opposite}}{\text{Adjacent}}\)
• \(\csc\theta = \frac{1}{\sin\theta}\)
• \(\sec\theta = \frac{1}{\cos\theta}\)
• \(\cot\theta = \frac{1}{\tan\theta}\)
Fundamental Identities:
• \(\sin^2\theta + \cos^2\theta = 1\)
• \(1 + \tan^2\theta = \sec^2\theta\)
• \(1 + \cot^2\theta = \csc^2\theta\)
• \(\tan\theta = \frac{\sin\theta}{\cos\theta}\)
• \(\sin(90^\circ - \theta) = \cos\theta\)
• \(\cos(90^\circ - \theta) = \sin\theta\)

📚 Chapter 7 – Coordinate Geometry

➕

Key Concepts: This chapter introduces the Cartesian coordinate system and covers fundamental concepts including distance between points, midpoint formula, slope of a line, and graphing linear equations. It includes applications of coordinate geometry in solving geometric problems.

Key Formulas:
• Distance Formula: \(d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)
• Midpoint Formula: \(M(x,y)=\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)\)
• Slope: \(m = \frac{y_2 - y_1}{x_2 - x_1}\)
• Point-Slope Form: \(y - y_1 = m(x - x_1)\)
• Slope-Intercept Form: \(y = mx + c\)
• General Form: \(ax + by + c = 0\)

📖 Chapter 8 – Logic

➕

Key Concepts: This chapter introduces the basics of mathematical logic including statements, truth tables, logical connectives (and, or, not, if-then, if and only if), and logical equivalence. It also covers methods of proof such as direct proof and proof by contradiction.

Logical Connectives:
• Conjunction (AND): \( p \land q \)
• Disjunction (OR): \( p \lor q \)
• Negation (NOT): \( \lnot p \)
• Conditional: \( p \to q \)
• Biconditional: \( p \leftrightarrow q \)
• Tautology: Always true (e.g., \( p \lor \lnot p \))
• Contradiction: Always false (e.g., \( p \land \lnot p \))

📙 Chapter 9 – Similar Figures

➕

Key Concepts: Similarity of figures; triangle criteria (AA, SAS, SSS); scale factor \(k\); relations for sides, perimeters, areas and volumes.

Similarity Criteria for Triangles:
• AA: two corresponding angles equal, e.g. \(\angle A=\angle D,\ \angle B=\angle E\).
• SAS: two sides proportional and included angle equal. If \(\dfrac{AB}{DE}=\dfrac{AC}{DF}=k\) and \(\angle A=\angle D\), then \(\triangle ABC\sim\triangle DEF\).
• SSS: three pairs of corresponding sides proportional: \(\dfrac{AB}{DE}=\dfrac{BC}{EF}=\dfrac{CA}{FD}=k\).
Consequences (scale factor \(k\)):
• Corresponding sides: \(AB = k\cdot DE\).
• Perimeters: \(\dfrac{P_{1}}{P_{2}} = k\).
• Areas: \(\dfrac{\text{Area}_1}{\text{Area}_2} = k^{2}\).
• Volumes (similar solids): \(\dfrac{V_{1}}{V_{2}} = k^{3}\).

📙 Chapter 13 – Probability

➕

Key Concepts: This chapter introduces the fundamentals of probability, including sample space, events, theoretical probability, experimental probability, complementary events, and real-life applications.

Important Formulas:
• Theoretical Probability: \( P(E) = \dfrac{\text{Number of favorable outcomes}}{\text{Total possible outcomes}} \)
• Experimental Probability: \( \dfrac{\text{Number of times event occurs}}{\text{Total trials}} \)
• Probability Range: \( 0 \leq P(E) \leq 1 \)
• Complementary Events: \( P(\text{not }E) = 1 - P(E) \)
• Equally Likely Outcomes: \( P(E) = \dfrac{n(E)}{n(S)} \)
