How to compress an image online for free

Large images slow down web pages, fill up phone storage and exceed the upload limits of forms and email. This tool re-encodes a JPG, PNG or WebP image at a lower quality and, if you wish, at smaller pixel dimensions. You see the new file size straight away, compare the result with the original, and download the file only when you are happy with it. It works the same way on a phone, tablet or computer: tap or click the drop area to choose a photo, or drag a file onto it on a desktop. The work is done by your browser, so compression does not use the network.

  1. Drag an image onto the drop area, or select it with the keyboard or the file picker.
  2. To reach a specific file size, choose a Target file size such as 100 KB, or pick Custom and enter your own. Otherwise leave No target selected and use the quality slider.
  3. Leave the output format on Same as original, or pick JPEG, WebP or PNG.
  4. Without a target, move the Quality slider. The compressed size updates a moment after you stop moving it.
  5. Optionally change the width or height, or press a scale preset. With Keep aspect ratio on, the other value follows automatically.
  6. Check the before-and-after comparison, then press Download compressed image. Use Copy Result to copy the size summary.

Compress an image to 20 KB, 50 KB, 100 KB, 200 KB or 1 MB

Forms, email services and content systems often state a maximum file size. When you select a target, the compressor looks for the highest quality that produces a file at or below that size. If lowering the quality alone is not enough, it reduces the dimensions in proportion, keeps the aspect ratio, never enlarges the image, and searches again. It prefers to shrink the dimensions before letting quality fall below 50%. The result panel shows the actual file size and whether the target was reached.

When a target size cannot be reached

The tool aims for the highest quality at or below your target, so the result is usually a little under it, not exactly equal. A target cannot always be met, and the tool will not pretend otherwise. In that case it says so and offers the smallest result it produced, which you can still download.

  • PNG output. PNG is lossless, so only a smaller image can reduce its size. Choose WebP or JPEG to keep more of the original dimensions.
  • Very small targets. The tool never makes the shorter side smaller than 64 px, and it goes below 50% quality only at that smallest size, never below 10%.
  • Small maximum dimensions. Width and height act as maximum sizes in target mode, so a small starting size leaves less room to reduce.
  • Unit differences. Here 1 KB is 1,024 bytes and 1 MB is 1,048,576 bytes. If a strict upload form counts 1 KB as 1,000 bytes and rejects a file just under its limit, choose a slightly smaller custom target.

How quality, dimensions and format affect file size

The browser decodes your file into pixels, draws them onto an off-screen canvas at the width and height you set, and encodes the canvas again with its built-in image encoder. Three things determine the final size.

Quality (JPEG and WebP)

JPEG and WebP are lossy formats. The quality setting tells the encoder how much fine detail it may discard. Lower values discard more detail and give smaller files. The exact saving depends on the picture: smooth gradients and soft photographs compress more than sharp text or noisy textures.

Pixel dimensions and aspect ratio

The number of pixels is width × height, so reducing both dimensions shrinks the file quickly. Halving the width and height leaves a quarter of the pixels. With Keep aspect ratio on, changing the width recalculates the height (and the other way round), so the picture is not stretched. The scale buttons shrink both together. This tool does not enlarge images, because that adds size without adding detail.

Choosing JPEG, PNG or WebP

  • JPEG suits photographs. It cannot store transparency, so transparent pixels are filled with the colour you choose. It is also the safe choice when a form asks specifically for a JPG file.
  • PNG is lossless: it throws no detail away, so the quality slider has no effect. It suits logos, screenshots and graphics with sharp edges or transparency, and shrinks mainly through smaller dimensions or by converting to WebP or JPEG.
  • WebP supports lossy compression and transparency, and is often smaller than JPEG or PNG at similar quality. If your browser cannot create WebP files, that option is turned off. Some older websites and programs do not accept WebP, so check before you upload it.

Compressing images for websites, email, forms and documents

  • Websites. Resize the image to the widest size the page actually displays, then compress. JPEG or WebP works well for photographs, and PNG or WebP for logos and graphics.
  • Email attachments. Choose a target such as 1 MB, or a custom size below your email provider’s attachment limit.
  • Online forms. Read the stated maximum size, file type and pixel dimensions first. Pick the matching preset or a custom size, and choose JPEG or PNG explicitly if the form names one. For Pakistani BISE registration forms that ask for a 130 × 130 px JPG under 20 KB, the BISE picture resizer is the purpose-built tool — it uses the same in-browser processing.
  • Document submissions. For photos or scans of documents, legible text matters more than the smallest possible file. Prefer a larger target such as 200 KB or 1 MB, and zoom in on the text before you download.

Practical examples

Example 1: A phone photo for a website

  1. A phone photo is 4000 × 3000 px, which is 12 million pixels. A blog column rarely shows it wider than about 1600 px.
  2. Set the width to 1600 with the aspect ratio locked. The height becomes 1200, so the picture has 1.92 million pixels, about 84% fewer.
  3. Keep JPEG or WebP at quality 80 and compare. The file is usually far smaller, and the difference is hard to see at normal viewing size.

Example 2: A photo for a form with a size limit

  1. The form accepts JPG files up to 100 KB. Choose the 100 KB target and set the output format to JPEG.
  2. Read the result panel. If it says Target reached, check faces and text in the comparison. It also tells you if the dimensions were reduced.
  3. If the target was not reached, or the picture looks too soft, check whether the form allows a larger file, then try again.

Example 3: A logo with a transparent background

  1. Load the PNG. Keep the format as Same as original, or choose WebP.
  2. Both formats preserve transparency. The comparison area shows a chequered pattern behind transparent parts.
  3. Avoid JPEG for this file unless you want a solid background colour.

Example 4: When compression does not help

  1. Upload an image that has already been compressed heavily, then re-encode it at a higher quality.
  2. The new file can come out larger than the original. The tool reports this as larger and warns you instead of calling it a saving.
  3. Lower the quality or the dimensions, or keep the original file.

How to check image quality before downloading

  • Drag the comparison slider across the picture to see the original and the compressed version side by side.
  • Zoom in on text, faces, edges and smooth gradients. Blocky patches, fuzzy outlines and visible banding are signs of too much compression.
  • Judge the image at the size it will actually be shown, not only zoomed in.
  • Check the output line in the result panel for the format and the pixel dimensions.
  • Keep your original file. Lossy compression cannot be undone.

Limitations to know about

  • Re-compression loses detail. Lossy compression cannot be undone, so keep your original file.
  • Target sizes are ceilings, not exact values. The result is at or below the target when it can be reached, and usually a little under it.
  • Metadata is removed. Canvas re-encoding drops EXIF data such as camera model and GPS position. This helps privacy, but it also removes copyright fields.
  • Colour profiles. Embedded colour profiles are not kept. Most images look the same, but wide-gamut or print-oriented files may shift slightly.
  • Animation. Only the first frame of an animated WebP or PNG is kept. GIF files are not supported.
  • Very large images. Files over 25 MB or 40 megapixels are refused, and some phones may not be able to process very large images. A target search encodes the image several times, so it can take a few seconds on large photos.

FAQ

Is my image uploaded to a server?▾

No. The image is read and re-encoded by your browser using the Canvas API, and this tool has no upload code. The only thing it passes to analytics is the name of an action such as “download”, never your image or its file name. Like the rest of the site, the page loads Google Analytics and Google advertising scripts; see the Privacy Policy for details.

Can it compress an image to exactly 100 KB?▾

Not exactly. Browsers cannot encode to an exact byte count, so the tool searches for the highest quality that stays at or below the target. The result is normally a little under it. If the target cannot be reached, the tool says so and offers the closest result.

Why does my image look blurry at 20 KB or 50 KB?▾

Such small files leave very little data for detail, so the tool must reduce the dimensions and quality a lot. Choose a larger target if the form allows it, use JPEG or WebP for photographs, and check the comparison slider before you download.

What image quality should I choose?▾

For photographs, 70 to 85 is a common range that keeps most of the visible detail. Use the comparison slider to check your own image, since screenshots, text and detailed textures may need a higher value. If you only need a particular file size, use a target instead and let the tool choose.

Why is my compressed PNG not much smaller?▾

PNG is lossless, so quality settings do not apply. Reduce the width and height, or switch the output to WebP or JPEG, to get a larger reduction.

Will transparency be preserved?▾

Yes for PNG and WebP output. JPEG does not support transparency, so transparent areas are filled with the background colour you pick, white by default.

Can I compress several images at once?▾

Not yet. This tool handles one image at a time. If you select several files, only the first is used. A target size you have chosen stays selected when you load the next image.

Does it work on a phone?▾

Yes. Tap the drop area to choose a photo from your gallery. Very large photos may be limited by your phone’s memory, in which case reduce the dimensions first.
