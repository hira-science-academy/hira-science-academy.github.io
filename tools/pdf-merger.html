    Merge PDF files into one document, free

    A PDF merger joins separate files into a single document so you can send, print or upload one thing instead of five. This free PDF merger handles PDFs, JPG and PNG pictures together. Drop them in, set the order, and download one PDF. The work happens in your browser, so there is nothing to install and no account to create.

    It suits students assembling an assignment from typed pages and photographed diagrams, job applicants combining a CV, certificates and an ID scan, and office staff packaging invoices for an accountant. Because the files never leave your device, you can also use it for documents you would rather not hand to a stranger’s server, although a trusted device is still wise for anything highly sensitive.

    What you can do

    • Combine PDFs. Every page of every file is added, in list order, with its original size and orientation.
    • Add images. JPG, JPEG and PNG files become pages. Portrait and landscape pictures each get a suitable page.
    • Mix both. Put an image between two PDFs, or finish a report with a scanned signature page.
    • Reorder. Drag the handle, use the arrow buttons, sort by name or remove a file you added by mistake.
    • Choose image page settings. A4, US Letter, Legal, A3, A5 or the original image size, with automatic or fixed orientation and optional margins.
    • Rename the result. Type the file name you want before you download.

    How to combine PDF files in four steps

    1. Add your files by dragging them onto the drop area or tapping it. Small previews, file types, page counts and sizes appear in a list.
    2. Arrange the list. File 1 is first in the merged PDF. Use + Add more files if you forgot one.
    3. Check the output settings. They only affect images, because PDF pages are kept exactly as they are. Type a name for the merged file.
    4. Press the merge button, then Download merged PDF. To start a new job without reloading, press Merge another set.

    Merging images into a PDF: page size and quality

    For image files, fit to page sizes (A4, Letter and the others) scale each picture up or down so it sits fully inside the page, centred, never stretched or cropped. With Original image size, each page matches its picture, which suits screenshots and artwork. Automatic orientation turns wide pictures into landscape pages, so a batch of mixed photos needs no manual work.

    Phone photos often carry a hidden rotation flag instead of being stored upright. The merger reads that flag and straightens the picture, which means such a photo is re-encoded once at high quality. Other JPG files are placed into the PDF without any re-compression.

    Optional image optimisation, explained plainly

    This is a merger, not a PDF compressor. Pages that come from PDFs are copied exactly and are not made smaller. If your result is too big because of photos, you can switch on image optimisation, which re-encodes the image files you added as JPEG at a lower quality and a smaller pixel size.

    • Off keeps images as they are. Choose this when quality matters most.
    • Balanced uses JPEG 85% and limits the long side to 2400 pixels. Text in scans stays readable.
    • Smaller file uses JPEG 70% and limits the long side to 1600 pixels. Fine detail can soften, and transparent PNG areas become white.

    For finer control, shrink pictures first with the image compressor, then merge them.

    Supported files and limits

    • Accepted: PDF, JPG, JPEG and PNG. The tool checks the real file type, not only the extension. WebP, HEIC, GIF and other formats are refused with a message that names the file.
    • Size: up to 100 files per job, 300 MB per PDF, 50 MB per image and 600 MB in total. Your device’s memory may set a lower practical limit.
    • Protected PDFs: password-protected or encrypted files cannot be opened and are listed as problems, while the other files still get added.
    • Document extras: page content is preserved. Bookmarks, form fields, tags and digital signatures belong to a whole document and are not carried into the merged file.
    • No text recognition: pictures stay pictures. A merged scan is not searchable unless the pages already contain text.

    Private by design

    The merger reads your files with your browser’s own file access, combines them with the open-source pdf-lib library and hands you the result as a download. The first time you add a PDF, the page fetches that library and, for small previews, Mozilla’s pdf.js. Your documents are not part of those requests and this tool has no upload code.

    Analytics receives only the name of an action, such as “merge” or “download”. File names, contents and page counts are never sent. Like the rest of the site, the page loads Google Analytics and Google advertising scripts; the Privacy Policy explains how they are used.

    Merge, then finish the job

    People who search for tools such as iLovePDF or Adobe Acrobat’s combine feature usually want one tidy file. This is an independent tool from Hira Science Academy and has no affiliation with those products. After merging, you can take the result a step further:

    Frequently asked questions

    How can I merge PDF files online for free?▾

    Drag your PDF files onto the drop area, put them in the order you want, and press the merge button. The combined PDF is created in your browser and you download it straight away. It costs nothing and needs no account.

    Can I merge multiple PDF files?▾

    Yes. Add up to 100 files in one go, or keep pressing Add more files. Each PDF contributes all of its pages, in the order shown in the list.

    Can I combine JPG images into one PDF?▾

    Yes. JPG, JPEG and PNG pictures become one page each. You choose the page size, orientation and margin, and you can put the pictures in any order. For more image-only options, the Image to PDF converter on this site is also available.

    Can I merge images and PDF documents together?▾

    Yes. A single list can hold PDFs and images side by side. A scanned ID photo can sit between two PDF documents, for example, and the final file follows the order of your list exactly.

    Can I rearrange PDF files before merging?▾

    Yes. Drag the handle at the left of a file to move it, or use the up and down arrows. You can also remove files, sort them by name or clear the whole list. Page numbers on the badges show the order of the files.

    Is this PDF merger free?▾

    Yes. There is no charge, no watermark and no limit on how many times you use it.

    Can I merge PDFs without signing up?▾

    Yes. You do not create an account or give an email address, and nothing you add is uploaded anywhere.

    Does merging reduce PDF quality?▾

    Not by default. PDF pages are copied as they are, so text, vector drawings and embedded images keep their quality, and JPG photos are placed unchanged. Quality only changes if you turn on image optimisation, which re-encodes images as JPEG, or if a photo has a camera rotation flag that has to be applied.

    Can I merge large PDF files?▾

    Within limits. Each PDF can be up to 300 MB and the files together up to 600 MB, but your device’s memory is the real limit. A laptop handles big files better than a phone. If the browser runs out of memory, the tool says so instead of producing a broken file.

    Do I need Adobe Acrobat to merge PDFs?▾

    No. This runs in any modern browser, so you do not need Adobe Acrobat or any other program. It is an independent tool and is not connected to Adobe or other PDF services.

    Can I merge password-protected PDFs?▾

    Not directly. Encrypted or password-protected PDFs cannot be opened by this tool, and it names the file that caused the problem. Remove the protection in the program that created it, if you are allowed to, then add the file again.
