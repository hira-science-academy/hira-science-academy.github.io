What this grade point converter does

Grades are written in three common ways — a letter (A, B+, C), a percentage (87%), or a GPA value on the 4.0 scale (3.55). This tool converts between all three. Enter any one representation, and the calculator returns the equivalent values in the other two, using a widely published conversion table. The full table is displayed below the result, with the matching row highlighted, so you can see exactly which band your input fell into and what the surrounding bands are. Because institutions differ in their cutoffs, the educational content includes a written disclaimer: your official grade sheet is the authority, not this calculator.

Formula and assumptions

Percentage → GPA (piecewise linear within a band)
GPA = GPAlo + (Percentage − %lo) × GPAhi − GPAlo %hi − %lo
GPA → Percentage (inverse of the above)
Percentage = %lo + (GPA − GPAlo) × %hi − %lo GPAhi − GPAlo

Assumptions this calculator makes

  • Scale: 4.0 maximum (no 4.5 or 5.0 scales).
  • Letter-to-percentage: the table above.
  • Percentage-to-GPA: the piecewise-linear mapping within each band, so 87% maps to 3.87 (0.87 of the way from 80 to 89 within the A band), not to a flat 3.7.
  • Rounding: results are rounded to two decimal places for display.
  • Grade point averages used for bands (for percentage → GPA): the endpoints of each band's GPA range.

Worked examples

Example 1: Letter → Percentage → GPA

Input: A
  1. Letter A sits in the 80–89% band.
  2. Representative percentage (midpoint): (80 + 89) / 2 = 84.5%.
  3. GPA range for A: 3.70 – 3.99. Midpoint: 3.85.
  4. So A ≈ 84.5% ≈ 3.85 GPA.

Example 2: Percentage → GPA (within a band)

Input: 87%
  1. 87% falls in the A band (80–89%).
  2. GPA range for A: 3.70 – 3.99.
  3. Linear interpolation: GPA = 3.70 + (87 − 80) × (3.99 − 3.70) / (89 − 80).
  4. GPA = 3.70 + 7 × 0.29 / 9 = 3.70 + 0.2256 = 3.93.
  5. Letter: A. Percentage: 87%. GPA: 3.93.

Example 3: Percentage → GPA at a band boundary

Input: 70%
  1. 70% is the lower edge of the B+ band (70–74%).
  2. GPA at the lower edge of B+: 3.30.
  3. Letter: B+.
  4. Boundary values are the only place where two adjacent bands share a value; the calculator assigns the higher band.

Example 4: GPA → Percentage

Input: GPA 3.55
  1. 3.55 falls in the A- GPA band (3.50 – 3.69).
  2. Percentage band for A-: 75 – 79%.
  3. Inverse interpolation: Percentage = 75 + (3.55 − 3.50) × (79 − 75) / (3.69 − 3.50).
  4. Percentage = 75 + 0.05 × 4 / 0.19 = 75 + 1.0526 = 76.05%.
  5. Letter: A-. GPA: 3.55. Percentage: 76.05%.

Example 5: Failing range

Input: 32%
  1. 32% falls in the F band (0–39%).
  2. GPA: 0.00.
  3. Letter: F.
  4. All percentages below 40% map to GPA 0.00 in this table.

Example 6: Perfect score

Input: 95%
  1. 95% falls in the A+ band (90–100%).
  2. GPA: 4.00 (the entire A+ band maps to 4.00).
  3. Letter: A+.
  4. Any percentage from 90 to 100 maps to a GPA of 4.00 in this table — the A+ band is flat, not linearly interpolated.

Why three representations exist

Different contexts call for different representations. Each has its purpose:

  • Percentages — used by BISE boards and schools for class 9, 10, F.Sc and matric results. They express raw performance on a 0–100 scale and make no assumption about how the marks were earned.
  • Letter grades — used by schools and universities as a categorical summary. They compress a percentage band into a single symbol, which is simpler to read on a transcript but loses fine-grained information.
  • GPA — used by universities and professional programmes. It is a numeric average across all courses, weighted by credit hours. The 4.0 scale is standard in Pakistan and the US.

Because each representation has its own granularity, converting between them is inherently lossy. A single letter grade corresponds to a range of percentages, not one value, and a GPA is an average, so it can also correspond to many percentage combinations.

Common mistakes to avoid

  • Assuming your institution uses this exact table. Cutoffs vary. HEC-published tables differ slightly from school boards. Always verify against your official grade sheet.
  • Confusing GPA with CGPA. GPA is a single term; CGPA is a running average across all terms. This tool converts a single GPA value — for CGPA, use the CGPA calculator.
  • Treating a converted GPA as exact. Converting a percentage to a GPA is a mapping, not a calculation. Two universities with different tables will produce different GPAs from the same percentage.
  • Using a converted GPA on official forms. Never put a converted value on an application form unless the form explicitly tells you to convert. Use the value printed on your transcript.
  • Assuming 90% always equals 4.0. In many tables it does, but some Pakistani universities cap the 4.0 grade at 85% or higher. Check your university's published grade boundaries.
  • Forgetting that practicals and theory are usually combined before conversion. A combined percentage (theory + practical) is what gets converted, not the two components separately.

FAQ

What is a grade point converter?▾

A grade point converter translates one representation of a grade into another. You enter a letter grade (A, B+, C), a percentage (85%), or a GPA on the 4.0 scale (3.5), and the tool shows the equivalent values in the other two formats using a published conversion table.

How does a letter grade map to a percentage?▾

It depends on the institution. A widely used mapping is A+ = 90-100%, A = 80-89%, B+ = 75-79%, B = 70-74%, C+ = 65-69%, C = 60-64%, D = 50-59%, and F below 50%. Pakistani universities and BISE boards vary, so always check your institution's official grade sheet.

How does a percentage map to GPA on the 4.0 scale?▾

A common mapping is 90-100% = 4.0, 80-89% = 3.7-3.9, 70-79% = 3.0-3.6, 60-69% = 2.0-2.9, 50-59% = 1.0-1.9, below 50% = 0.0. The exact cutoffs vary by university — the HEC and most Pakistani universities publish their own conversion tables.

Why does my university's GPA differ from this calculator?▾

Universities use different conversion tables, different round-off rules, and sometimes different scale maxima (4.0, 4.5, 5.0). This calculator uses a widely published 4.0-scale table. Your institution's official conversion is the authority.

Can I convert a GPA back to a percentage?▾

Yes. Enter the GPA on the 4.0 scale and the calculator returns an approximate percentage range. The conversion is approximate because a single GPA value can correspond to a range of percentages depending on the original grading scheme.

What is the difference between a letter grade and a grade point?▾

A letter grade is a categorical label (A, B+, C). A grade point is the numeric value that label maps to on a scale, typically 0.0 to 4.0. The GPA is the credit-weighted average of grade points across all your courses.
