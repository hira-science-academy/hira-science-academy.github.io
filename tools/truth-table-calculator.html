What this truth table calculator does

This tool takes any Boolean logic expression — built from variables A through E, the operators AND, OR, NOT, XOR, IMPLIES and IFF, and parentheses — and generates its complete truth table. Every row of the table shows one of the \(2^n\) possible combinations of truth values, the value of each intermediate subexpression, and the final result of the whole expression. The calculator then classifies the expression as a tautology (true in every row), a contradiction (false in every row), or contingent (true in some rows, false in others). The final column is highlighted so you can read the result at a glance, and a summary panel shows the row counts, the parse tree size, and the number of intermediate columns.

Operator precedence (highest to lowest): NOT (\( \neg \)), then AND (\( \land \)), then OR (\( \lor \)) / XOR (\( \oplus \)), then IMPLIES (\( \to \)), then IFF (\( \leftrightarrow \)). Use parentheses to override.

Worked examples

Example 1: \( (A \land B) \lor \neg C \) — contingent

  1. Three variables → \( 2^3 = 8 \) rows.
  2. Intermediate columns: \( A \land B \), \( \neg C \), and the final \( (A \land B) \lor \neg C \).
  3. The final column is \( T \) in some rows and \( F \) in others → contingent.
  4. A classic three-variable logic expression that appears in Karnaugh map problems.

Example 2: \( A \lor \neg A \) — tautology

  1. One variable → 2 rows.
  2. Intermediate columns: \( \neg A \), then \( A \lor \neg A \).
  3. The final column is \( T \) in every row → tautology (the law of excluded middle).

Example 3: \( A \land \neg A \) — contradiction

  1. One variable → 2 rows.
  2. Intermediate columns: \( \neg A \), then \( A \land \neg A \).
  3. The final column is \( F \) in every row → contradiction (the law of non-contradiction).

Example 4: \( (A \to B) \leftrightarrow (\neg A \lor B) \) — tautology

  1. Two variables → 4 rows.
  2. This is the classic material implication equivalence. Both sides evaluate identically in every row.
  3. The final column is \( T \) everywhere → tautology.
  4. Shows that \( A \to B \) can be rewritten as \( \neg A \lor B \).

Example 5: \( A \oplus B \oplus C \) — parity function

  1. Three variables → 8 rows.
  2. XOR is associative, so the result is \( T \) when an odd number of the three variables are true.
  3. Four of the eight rows give \( T \), four give \( F \) → contingent.
  4. This is the Boolean parity function, used in error checking and cryptography.

Common mistakes to avoid

  • Mixing operator symbols without consistency. The calculator accepts \( \neg \) and \( \sim \) and \( ! \) for NOT, but within one expression it is clearer to pick one style. Mixed notation confuses readers even when the parser handles it.
  • Forgetting parentheses when precedence matters. \( A \land B \lor C \) parses as \( (A \land B) \lor C \) because AND binds tighter than OR. If you mean \( A \land (B \lor C) \), write the parentheses.
  • Assuming IMPLIES is symmetric. \( A \to B \) and \( B \to A \) are different expressions. Implication is not commutative — the table makes the asymmetry obvious.
  • Reading IFF as "exclusive". IFF (biconditional, \( \leftrightarrow \)) means "both or neither" — it is true when \( A \) and \( B \) have the same truth value. XOR (\( \oplus \)) means "exactly one" — it is true when they differ. These are opposites.
  • Forgetting that implication with a false premise is true. \( F \to \text{anything} \) is \( T \). This surprises students but follows directly from the truth table definition; implication only fails when the premise is true and the conclusion is false.
  • Counting rows wrong. \( n \) variables → \( 2^n \) rows, always. Four variables is 16 rows; five is 32; six is 64. If your table doesn't have the right row count, variables are duplicated or missing.

FAQ

What is a truth table?▾

A truth table is a table that lists every possible combination of truth values (true or false) for the variables in a logical expression, along with the resulting value of the expression for each combination. With \( n \) variables, the table has \( 2^n \) rows. Truth tables are used to analyse Boolean logic expressions, verify logical equivalences, and determine whether an expression is a tautology, contradiction, or contingent.

What operators does this tool support?▾

The tool supports NOT (\( \neg \) or \( \sim \) or \( ! \)), AND (\( \land \) or & or &&), OR (\( \lor \) or | or ||), XOR (\( \oplus \) or ^), IMPLIES (\( \to \) or -> or =>), IFF / biconditional (\( \leftrightarrow \) or <-> or <=>), and parentheses. You can mix symbolic and word-like operators in the same expression.

What is the difference between a tautology, contradiction, and contingent expression?▾

A tautology is an expression that is true for every row of its truth table — for example, \( A \lor \neg A \). A contradiction is an expression that is false for every row — for example, \( A \land \neg A \). A contingent expression is true for some rows and false for others — for example, \( A \land B \). The calculator labels every expression with one of these three verdicts.

How are variables ordered in the table?▾

Variables are ordered alphabetically from left to right. The first variable alternates T/F every row, the next every two rows, and so on — the standard truth table convention that produces the canonical \( 2^n \) row ordering.

Why is there a limit on variables?▾

With \( n \) variables, the table has \( 2^n \) rows. Five variables is 32 rows, which is still readable; six variables is 64 rows and ten variables would be 1024 rows. The calculator caps the expression at five distinct variables to keep the output useful. Most textbook problems use two or three.

Can I use this to check logical equivalences?▾

Yes. Two expressions are logically equivalent if their truth tables have the same final column. Generate the table for one expression, then the other, and compare the last column. A quick alternative is to test the biconditional of the two expressions — if the result is a tautology, the expressions are equivalent.
