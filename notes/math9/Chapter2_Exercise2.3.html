📌 Important Rules for Characteristic & Mantissa

  • For numbers greater than 1: Characteristic = (number of digits to the left of decimal point) - 1
  • For numbers less than 1: Characteristic = -(number of zeros between decimal point and first non-zero digit + 1)
  • Logarithm formula: Logarithm = Characteristic + Mantissa
  • Antilogarithm: The value obtained from the log table based on the mantissa; the decimal point is placed according to the characteristic.

Q2 Find the logarithm of the following numbers:
(i) 43 (ii) 579 (iii) 1.982 (iv) 0.0876 (v) 0.047 (vi) 0.000354
Solution

(i) \(\log 43\)

Characteristic = 2 - 1 = 1
Mantissa = 0.6335 (Table Value = 6335)
\(\log 43 = 1 + 0.6335\)
\(\log 43 = 1.6335\)

(ii) \(\log 579\)

Characteristic = 3 - 1 = 2
Mantissa = 0.7627 (Table Value = 7627)
\(\log 579 = 2 + 0.7627\)
\(\log 579 = 2.7627\)

(iii) \(\log 1.982\)

Characteristic = 1 - 1 = 0
Mantissa = 0.2971 (Table Value = 2967 + 4 = 2971)
\(\log 1.982 = 0 + 0.2971\)
\(\log 1.982 = 0.2971\)

(iv) \(\log 0.0876\)

Characteristic = -(1 + 1) = -2
Mantissa = 0.9425 (Table Value = 9425)
\(\log 0.0876 = -2 + 0.9425\)
\(\log 0.0876 = -1.0575\)

(v) \(\log 0.047\)

Characteristic = -(1 + 1) = -2
Mantissa = 0.6721 (Table Value = 6721)
\(\log 0.047 = -2 + 0.6721\)
\(\log 0.047 = -1.3279\)

(vi) \(\log 0.000354\)

Characteristic = -(3 + 1) = -4
Mantissa = 0.5490 (Table Value = 5490)
\(\log 0.000354 = -4 + 0.5490\)
\(\log 0.000354 = -3.4510\)
Q3 If \(\log 3.177 = 0.5019\), then find:
(i) \(\log 3177\) (ii) \(\log 31.77\) (iii) \(\log 0.03177\)
Solution

Given: \(\log 3.177 = 0.5019\). So, Characteristic = 0 and Mantissa = 0.5019

(i) \(\log 3177\)

Characteristic = 4 - 1 = 3
Mantissa = 0.5019
\(\log 3177 = 3 + 0.5019\)
\(\log 3177 = 3.5019\)

(ii) \(\log 31.77\)

Characteristic = 2 - 1 = 1
Mantissa = 0.5019
\(\log 31.77 = 1 + 0.5019\)
\(\log 31.77 = 1.5019\)

(iii) \(\log 0.03177\)

Characteristic = -(1 + 1) = -2
Mantissa = 0.5019
\(\log 0.03177 = -2 + 0.5019\)
\(\log 0.03177 = -1.4981\)
Q4 Find the value of \(x\):
(i) \(\log x = 0.0065\) (ii) \(\log x = 1.192\) (iii) \(\log x = -3.434\) (iv) \(\log x = -1.5726\) (v) \(\log x = 4.3561\) (vi) \(\log x = -2.0184\)
Solution

(i) \(\log x = 0.0065\)

Characteristic = 0, Mantissa = 0.0065
Table value of 0.0065 = 1014 + 1 = 1,015
\(x = \text{Anti log } 0.0065\)
\(x = 1.015\) (decimal at reference position)

(ii) \(\log x = 1.192\)

Characteristic = 1, Mantissa = 0.192
Table value of 0.192 = 1,556
\(x = \text{Anti log } 1.192\)
\(x = 15.56\) (decimal after 1 digit right from reference)

(iii) \(\log x = -3.434\)

\(\log x = -4 + 4 - 3.434\)
\(\log x = -4 + 0.566\)
Characteristic = -4, Mantissa = 0.566
Table value of 0.566 = 3,681
\(x = \text{Anti log } \bar{4}.566\)
\(x = 0.0003681\) (decimal before 4 digits left)

(iv) \(\log x = -1.5726\)

\(\log x = -2 + 2 - 1.5726\)
\(\log x = -2 + 0.4274\)
Characteristic = -2, Mantissa = 0.4274
Table value of 0.4274 = 2673 + 2 = 2,675
\(x = \text{Anti log } \bar{2}.4274\)
\(x = 0.02675\) (decimal before 2 digits left)

(v) \(\log x = 4.3561\)

Characteristic = 4, Mantissa = 0.3561
Table value of 0.3561 = 2270 + 1 = 2,271
\(x = \text{Anti log } 4.3561\)
\(x = 22710\) (decimal after 4 digits right)

(vi) \(\log x = -2.0184\)

\(\log x = -3 + 3 - 2.0184\)
\(\log x = -3 + 0.9816\)
Characteristic = -3, Mantissa = 0.9816
Table value of 0.9816 = 9572 + 13 = 9,585
\(x = \text{Anti log } \bar{3}.9816\)
\(x = 0.009585\) (decimal before 3 digits left)

💡 Exam Tip:

Always write the characteristic and mantissa separately before combining them. For numbers between 0 and 1, write the characteristic in negative bar form (e.g., \(\bar{2}\)) to avoid confusion. When finding antilogarithms, pay close attention to the characteristic to correctly place the decimal point. The reference position is between the first and second non-zero digits.

❓ Frequently Asked Questions – Exercise 2.3

For any number greater than \(1\), the characteristic equals the number of digits to the left of the decimal point minus \(1\):

\(5287 \to 4 - 1 = 3\)
\(59.28 \to 2 - 1 = 1\)
\(234.7 \to 3 - 1 = 2\)

For a number less than \(1\), count the zeros between the decimal point and the first non-zero digit, add \(1\), then attach a negative sign:

\(0.0567 \to -(1 + 1) = -2\), written as \(\bar{2}\)
\(0.000049 \to -(4 + 1) = -5\), written as \(\bar{5}\)

The logarithm of any positive number is the sum of its characteristic and its mantissa:

\(\log x = \text{characteristic} + \text{mantissa}\)
\(\log 579 = 2.7627 \quad (2 \text{ is characteristic, } 0.7627 \text{ is mantissa})\)

The characteristic determines the position of the decimal point; the mantissa (always positive) is read from the log table.

For numbers less than \(1\), the characteristic is negative while the mantissa remains positive. Writing it as a single negative decimal (like \(-2.434\)) is ambiguous. Bar notation keeps the mantissa positive:

\(\log 0.047 = -2 + 0.6721 = \bar{2}.6721\)

Only the integer part (2) is negative; the mantissa \(0.6721\) is positive.

Look up the mantissa in the antilog table to get a four-digit number, then place the decimal point based on the characteristic:

\(\operatorname{antilog}(4.3561) = 22710\) (positive characteristic \(\Rightarrow\) decimal after 4+1 digits)
\(\operatorname{antilog}(\bar{2}.4274) = 0.02675\) (bar 2 \(\Rightarrow\) 2 zeros after the decimal)
