⚡ Key Concepts – Linear Equations

Linear Equation
\(ax + b = 0\)

An equation where the highest power of the variable is 1, with \(a \neq 0\).

Linear Inequality
\(ax + b < 0\)

An inequality comparing two expressions, using symbols like \(<, >, \leq, \geq\).

Inclusion-Exclusion
\(n(A \cup B) = n(A) + n(B) - n(A \cap B)\)

A formula to find the number of elements in the union of two sets without double-counting.

Objective Function
\(f(x, y) = ax + by\)

The function to be maximized or minimized subject to constraints.

Corner Point
Vertex of Feasible Region

A point where two boundary lines intersect in the feasible region.

Feasible Region
Intersection of Constraints

The area of the graph that satisfies all inequalities, often restricted to the first quadrant.

❓ Chapter 5 Frequently Asked Questions

What is a linear equation?

A linear equation is an equation in which the highest power of the variable is 1. It can be written in the form \(ax + b = 0\), where \(a \neq 0\).

What is the difference between an equation and an inequality?

An equation uses an equal sign (=) to show two expressions are equal, while an inequality uses symbols like <, >, ≤, or ≥ to show a relationship where values may not be equal.

How do you represent an inequality on a number line?

An open circle is used for \(<\) or \(>\), indicating the number is not included. A closed circle is used for \(\leq\) or \(\geq\), indicating the number is included. An arrow is drawn in the direction of the valid values.

What is a feasible region?

The feasible region is the area on a graph that satisfies all constraints (linear inequalities) of a system simultaneously. It is often restricted to the first quadrant in real-world problems.

How do you find the optimal solution using corner points?

Evaluate the objective function at each corner point of the feasible region. The maximum or minimum value among these evaluations is the optimal solution.
