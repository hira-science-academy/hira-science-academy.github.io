📝 Multiple Choice Questions (PECTAA 2025)

1. The set builder form of the set \(\{1, 1/2, 1/3, 1/4, \ldots\}\) is:

✅ Correct Answer: (A) \(\{x \mid x = 1/n, n \in \mathbb{W}\}\)
The elements are odd reciprocals, represented as \(1/(2n+1)\).

2. If \(A = \{\}\), then \(P(A)\) is:

✅ Correct Answer: (C) \(\{1\}\)
Power set of empty set = \(\{\{\}\}\) or \(\{\phi\}\).

3. If \(U = \{1, 2, 3, 4, 5\}\), \(A = \{1, 2, 3\}\) and \(B = \{3, 4, 5\}\), then \(U - (A \cap B)\) is:

✅ Correct Answer: (A) \(\{1, 2, 4, 5\}\)
\(A \cap B = \{3\}\), so \(U - A \cap B = \{1, 2, 4, 5\}\).

4. If \(A\) and \(B\) are overlapping sets, then \(n(A - B)\) is equal to:

✅ Correct Answer: (D) \(n(A) - n(A \cap B)\)
For overlapping sets, \(n(A - B) = n(A) - n(A \cap B)\).

5. If \(A \subseteq B\) and \(B - A \neq \phi\), then \(n(B - A)\) is equal to:

✅ Correct Answer: (D) \(n(B) - n(A)\)
\(B - A =\) elements only in \(B\), so \(n(B - A) = n(B) - n(A)\).

6. If \(n(A \cup B) = 50\), \(n(A) = 30\), and \(n(B) = 35\), then \(n(A \cap B) =\):

✅ Correct Answer: (C) 15
\(n(A \cap B) = n(A) + n(B) - n(A \cup B) = 30 + 35 - 50 = 15\).

7. If \(A = \{1, 2, 3, 4\}\) and \(B = \{x, y, z\}\), then the Cartesian product of \(A\) and \(B\) contains exactly _____ elements.

✅ Correct Answer: (B) 12
\(4 \text{ elements} \times 3 \text{ elements} = 12\).

8. If \(f(x) = x^2 - 3x + 2\), then the value of \(f(a + 1)\) is equal to:

✅ Correct Answer: (D) \(a^2 - a\)
\(f(a+1) = (a+1)^2 - 3(a+1) + 2 = a^2 + 2a + 1 - 3a - 3 + 2 = a^2 - a\).

9. Given that \(f(x) = 3x + 1\), if \(f(x) = 28\), then the value of \(x\) is:

✅ Correct Answer: (C) 9
\(f(x) = 3x + 1 = 28 \Rightarrow 3x = 27 \Rightarrow x = 9\).

10. Let \(A = \{1, 2, 3\}\) and \(B = \{a, b\}\); two non-empty sets and \(f: A \to B\) be a function defined as \(f = \{(1, a), (2, a), (3, b)\}\), then which of the following statements is true?

✅ Correct Answer: (B) \(f\) is surjective
Every element in \(B\) is mapped, so \(f\) is surjective.

❓ Frequently Asked Questions – Chapter 3 MCQs

The MCQs on this page cover: set builder notation, power sets, set operations (union, intersection, difference), Cartesian products, function evaluation and properties, types of functions (injective, surjective, bijective), and practical applications of set theory.

The set \(\{1, 1/2, 1/3, 1/4, \ldots\}\) can be written in set builder form as \(\{x \mid x = 1/n, n \in \mathbb{N}\}\) or \(\{x \mid x = 1/(n+1), n \in \mathbb{W}\}\). The correct answer is \(\{x \mid x = 1/n, n \in \mathbb{W}\}\) where \(\mathbb{W}\) is the set of whole numbers.

The power set of the empty set, denoted \(P(\emptyset)\), is the set of all subsets of the empty set. Since the empty set has only one subset (itself), \(P(\emptyset) = \{\emptyset\}\). This is a key concept tested in MCQ 2.

For overlapping sets, \(n(A - B) = n(A) - n(A \cap B)\). This formula subtracts the number of elements common to both sets from the total number of elements in A. For example, if \(A = \{1, 2\}\) and \(B = \{1\}\), then \(A \cap B = \{1\}\), so \(n(A - B) = 2 - 1 = 1\).

Use the inclusion-exclusion principle: \(n(A \cap B) = n(A) + n(B) - n(A \cup B)\). For example, if \(n(A \cup B) = 50\), \(n(A) = 30\), and \(n(B) = 35\), then \(n(A \cap B) = 30 + 35 - 50 = 15\).
