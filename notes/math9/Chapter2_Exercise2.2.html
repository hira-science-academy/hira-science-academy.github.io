📐 Exercise 2.2 – Questions & Solutions

Q1 Express each of the following in logarithmic form:
(i) \(10^{3} = 1000\) (ii) \(2^{8} = 256\) (iii) \(3^{-3} = \frac{1}{27}\) (iv) \(20^{2} = 400\) (v) \(16^{-\frac{1}{4}} = \frac{1}{2}\) (vi) \(11^{2} = 121\) (vii) \(p = q^{r}\) (viii) \((32)^{-\frac{1}{5}} = \frac{1}{2}\)
Solution
PartExponential FormLogarithmic Form
(i)\(10^{3} = 1000\)\(\log_{10} 1000 = 3\)
(ii)\(2^{8} = 256\)\(\log_{2} 256 = 8\)
(iii)\(3^{-3} = \frac{1}{27}\)\(\log_{3} \frac{1}{27} = -3\)
(iv)\(20^{2} = 400\)\(\log_{20} 400 = 2\)
(v)\(16^{-\frac{1}{4}} = \frac{1}{2}\)\(\log_{16} \frac{1}{2} = -\frac{1}{4}\)
(vi)\(11^{2} = 121\)\(\log_{11} 121 = 2\)
(vii)\(p = q^{r}\)\(\log_{q} p = r\)
(viii)\((32)^{-\frac{1}{5}} = \frac{1}{2}\)\(\log_{32} \frac{1}{2} = -\frac{1}{5}\)
Q2 Express each of the following in exponential form:
(i) \(\log_{5} 125 = 3\) (ii) \(\log_{2} 16 = 4\) (iii) \(\log_{23} 1 = 0\) (iv) \(\log_{5} 5 = 1\) (v) \(\log_{2} \frac{1}{8} = -3\) (vi) \(\frac{1}{2} = \log_{9} 3\) (vii) \(5 = \log_{10} 100000\) (viii) \(\log_{4} \frac{1}{16} = -2\)
Solution
PartLogarithmic FormExponential Form
(i)\(\log_{5} 125 = 3\)\(5^{3} = 125\)
(ii)\(\log_{2} 16 = 4\)\(2^{4} = 16\)
(iii)\(\log_{23} 1 = 0\)\(23^{0} = 1\)
(iv)\(\log_{5} 5 = 1\)\(5^{1} = 5\)
(v)\(\log_{2} \frac{1}{8} = -3\)\(2^{-3} = \frac{1}{8}\)
(vi)\(\frac{1}{2} = \log_{9} 3\)\(9^{\frac{1}{2}} = 3\)
(vii)\(5 = \log_{10} 100000\)\(10^{5} = 100000\)
(viii)\(\log_{4} \frac{1}{16} = -2\)\(4^{-2} = \frac{1}{16}\)
Q3 Find the value of \(x\) in each of the following:
(i) \(\log_{x} 64 = 3\) (ii) \(\log_{5} 1 = x\) (iii) \(\log_{x} 8 = 1\) (iv) \(\log_{10} x = -3\) (v) \(\log_{4} x = \frac{3}{2}\) (vi) \(\log_{2} 1024 = x\)
Solution

(i) \(\log_{x} 64 = 3\)

\(x^{3} = 64\)
\(x^{3} = 4^{3}\)
\(\Rightarrow x = 4\)

(ii) \(\log_{5} 1 = x\)

\(5^{x} = 1\)
\(5^{x} = 5^{0}\)
\(\Rightarrow x = 0\)

(iii) \(\log_{x} 8 = 1\)

\(x^{1} = 8\)
\(x = 8\)

(iv) \(\log_{10} x = -3\)

\(10^{-3} = x\)
\(\frac{1}{10^{3}} = x\)
\(\frac{1}{1000} = x\)
\(\Rightarrow x = \frac{1}{1000}\)

(v) \(\log_{4} x = \frac{3}{2}\)

\(4^{\frac{3}{2}} = x\)
\((2^{2})^{\frac{3}{2}} = x\)
\(2^{3} = x\)
\(8 = x\)
\(\Rightarrow x = 8\)

(vi) \(\log_{2} 1024 = x\)

\(2^{x} = 1024\)
\(2^{x} = 2^{10}\)
\(\Rightarrow x = 10\)

💡 Exam Tip:

Always remember the core conversion rule: \(a^b = c \iff \log_a c = b\). When solving for an unknown in a logarithm, first convert to exponential form, then express both sides with the same base. For example, if \(x^3 = 64\), express 64 as \(4^3\) to easily identify \(x = 4\).
