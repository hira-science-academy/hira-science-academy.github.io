📌 Important Revision Points

  • Class size: \(h = \text{upper limit} - \text{lower limit} + 1\) (inclusive classes).
  • Class boundary: subtract \(0.5\) from lower limit, add \(0.5\) to upper limit.
  • Class mark (midpoint): \(X = \dfrac{\text{lower boundary} + \text{upper boundary}}{2}\).
  • Range: \(X_{\max} - X_{\min}\).
  • Number of classes: choose \(k\), then class width \(h = \dfrac{\text{Range}}{k}\) rounded up.
  • Histogram: adjacent rectangles on class boundaries; height \(=\) frequency for equal widths, frequency density \(=\) \(f \div w\) for unequal widths.
  • Frequency polygon: plot \((\text{class mark}, f)\) points and close with empty classes at both ends.

📐 Exercise 12.1 – Questions & Solutions

Q1 The following distribution represents the scores achieved by a group of chemistry students in the chemistry laboratory. Answer the following questions.
Scores: 24–28, 29–33, 34–38, 39–43, 44–48, 49–53
No. of students: 3, 6, 12, 23, 15, 6 (Total 65)
Solution

(i) Upper limit of the last class

Last class is \(49 - 53\).

Upper limit \(= 53\)

(ii) Lower limit of the class 39 – 43

Lower limit \(= 39\)

(iii) Midpoint of the class 34 – 38

\(\text{Midpoint} = \dfrac{34 + 38}{2} = \dfrac{72}{2} = 36\)

(iv) Class frequencies of 29–33 and 44–48

Frequency of \(29-33 = 6\)
Frequency of \(44-48 = 15\)

(v) Size of class limits

\(\text{Class size} = 28 - 24 + 1 = 5\)

(vi) Class with minimum number of students

Minimum frequency \(= 3\) (class \(24 - 28\))

(vii) Lower limit of the class with frequency 15

Class with \(f = 15\) is \(44 - 48 \Rightarrow\) lower limit \(= 44\)

(viii) Number of students with scores between 24 and 43

Classes: \(24-28,\; 29-33,\; 34-38,\; 39-43\)
\(= 3 + 6 + 12 + 23 = 44\)
✅ (i) 53   (ii) 39   (iii) 36   (iv) 6 and 15   (v) 5   (vi) 24–28   (vii) 44   (viii) 44 students

Q7 The marks obtained by Grade-10 students in a mathematics test were grouped into the following frequency distribution. Draw a histogram for the distribution.
Marks: 35–37, 38–44, 45–54, 55–61, 62–67, 68–72
Frequency: 2, 12, 16, 13, 9, 3
Solution

The class widths are unequal, so the histogram height must be the frequency density, \(\text{height} = \dfrac{f}{w}\).

💡 Exam Tip:

Write the class boundaries in a table column before you draw anything — most histogram errors come from using class limits instead of boundaries. If the class widths are not equal, plot frequency density (frequency ÷ width) so the area under each bar still equals the frequency. For a frequency polygon, remember to include the two empty classes at the ends to close the shape, and to plot the class marks, not the boundaries. When the question asks for the tally bar method, always show the tally column — it is the working the examiner marks.

❓ Frequently Asked Questions – Exercise 12.1

Exercise 12.1 covers constructing frequency distribution tables, the tally bar method, class limits and class boundaries, class marks, drawing histograms (including histograms with unequal class intervals using frequency density), and constructing frequency polygons for grouped data.

The complete PDF is embedded near the top of this page and can also be opened with the "⬇️ Download PDF – Exercise 12.1 Solutions (Free)" button directly below the PDF viewer.

Class limits are the written ends of a class interval, such as 10–19. Class boundaries close the gap between consecutive intervals by adding 0.5 to the upper limit and subtracting 0.5 from the lower limit, giving 9.5–19.5. Histograms are drawn with class boundaries, not class limits.

When classes have unequal widths, the height of each bar must represent frequency density (frequency divided by class width) so that the area under each bar equals the frequency. Otherwise the visual comparison between classes is misleading. Question 7 of this exercise is a direct example of this rule.
