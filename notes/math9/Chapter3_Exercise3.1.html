📐 Exercise 3.1 – Questions & Solutions

Q1 Write the following sets in set builder notation:
(i) \(\{1, 4, 9, 16, 25, 36, \ldots, 484\}\) (ii) \(\{2, 4, 8, 16, \ldots, 256\}\) (iii) \(\{0, \pm 1, \pm 2, \ldots, \pm 1000\}\) (iv) \(\{6, 12, 18, \ldots, 120\}\) (v) \(\{100, 102, 104, \ldots, 400\}\) (vi) \(\{1, 3, 9, 27, 81, \ldots\}\) (vii) \(\{1, 2, 4, 5, 10, 20, 25, 50, 100\}\) (viii) \(\{5, 10, 15, \ldots, 100\}\)
Solution
PartSetSet-Builder Notation
(i)\(\{1, 4, 9, 16, 25, 36, \ldots, 484\}\)\(\{x \mid x = n^{2},\, n \in \mathbb{N} \wedge 1 \leq n \leq 22\}\)
(ii)\(\{2, 4, 8, 16, \ldots, 256\}\)\(\{x \mid x = 2^{n},\, n \in \mathbb{N} \wedge 1 \leq n \leq 8\}\)
(iii)\(\{0, \pm 1, \pm 2, \ldots, \pm 1000\}\)\(\{x \mid x \in \mathbb{Z} \wedge -1000 \leq x \leq 1000\}\)
(iv)\(\{6, 12, 18, \ldots, 120\}\)\(\{x \mid x = 6n,\, n \in \mathbb{N} \wedge 1 \leq n \leq 20\}\)
(v)\(\{100, 102, 104, \ldots, 400\}\)\(\{x \mid x = 100 + 2n,\, n \in \mathbb{W} \wedge 0 \leq n \leq 150\}\)
(vi)\(\{1, 3, 9, 27, 81, \ldots\}\)\(\{x \mid x = 3^{n},\, n \in \mathbb{W}\}\)
(vii)\(\{1, 2, 4, 5, 10, 20, 25, 50, 100\}\)\(\{x \mid x \text{ is a divisor of } 100\}\)
(viii)\(\{5, 10, 15, \ldots, 100\}\)\(\{x \mid x = 5n,\, n \in \mathbb{N} \wedge 1 \leq n \leq 20\}\)
Q2 Write each of the following sets in tabular form:
(i) \(\{x \mid x \text{ is a multiple of 3} \wedge x \leq 36\}\) (ii) \(\{x \mid x \in \mathbb{R} \wedge 2x + 1 = 0\}\) (iii) \(\{x \mid x \in \mathbb{P} \wedge x < 12\}\) (iv) \(\{x \mid x \text{ is a divisor of } 128\}\) (v) \(\{x \mid x = 2^{n},\, n \in \mathbb{N} \wedge n < 8\}\) (vi) \(\{x \mid x \in \mathbb{N} \wedge x + 4 = 0\}\) (vii) \(\{x \mid x \in \mathbb{N} \wedge x = x\}\) (viii) \(\{x \mid x \in \mathbb{Z} \wedge 3x + 1 = 0\}\)
Solution
PartSet-Builder FormTabular Form
(i)\(\{x \mid x \text{ is a multiple of } 3 \wedge x \leq 36\}\)\(\{3, 6, 9, 12, 15, 18, 21, 24, 27, 30, 33, 36\}\)
(ii)\(\{x \mid x \in \mathbb{R} \wedge 2x + 1 = 0\}\)\(\left\{\frac{1}{2}\right\}\) — solving \(2x + 1 = 0\) gives \(x = -\tfrac{1}{2}\)
(iii)\(\{x \mid x \in \mathbb{P} \wedge x < 12\}\)\(\{2, 3, 5, 7, 11\}\)
(iv)\(\{x \mid x \text{ is a divisor of } 128\}\)\(\{1, 2, 4, 8, 16, 32, 64, 128\}\)
(v)\(\{x \mid x = 2^{n},\, n \in \mathbb{N} \wedge n < 8\}\)\(\{2, 4, 8, 16, 32, 64, 128\}\)
(vi)\(\{x \mid x \in \mathbb{N} \wedge x + 4 = 0\}\)\(\emptyset\) (since \(x = -4 \notin \mathbb{N}\))
(vii)\(\{x \mid x \in \mathbb{N} \wedge x = x\}\)\(\{1, 2, 3, \ldots\}\)
(viii)\(\{x \mid x \in \mathbb{Z} \wedge 3x + 1 = 0\}\)\(\emptyset\) (since \(x = -\tfrac{1}{3} \notin \mathbb{Z}\))
Q3 Write two proper subsets of each of the following sets:
(i) \(\{a, b, c\}\) (ii) \(\{0, 1\}\) (iii) \(\mathbb{N}\) (iv) \(\mathbb{Z}\) (v) \(\mathbb{Q}\) (vi) \(\{x \mid x \in \mathbb{Q} \wedge 0 < x \leq 2\}\)
Solution
PartSetTwo Proper Subsets
(i)\(\{a, b, c\}\)\(\{a\},\ \{b\}\)
(ii)\(\{0, 1\}\)\(\{0\},\ \{1\}\)
(iii)\(\mathbb{N}\)Set of prime numbers, Set of even natural numbers
(iv)\(\mathbb{Z}\)Set of prime numbers, Set of whole numbers
(v)\(\mathbb{Q}\)Set of integers \(\mathbb{Z}\), Set of natural numbers \(\mathbb{N}\)
(vi)\(\{x \mid x \in \mathbb{Q} \wedge 0 < x \leq 2\}\)\(\left\{\tfrac{1}{2}\right\},\ \left\{\tfrac{3}{4}\right\}\)
Q4 Is there any set which has no proper subset? If so, name that set.
Solution

Yes, there exists a set that has no proper subset — it is called the empty set \(\{\}\) or \(\emptyset\). Its only subset is itself, so there is no distinct proper subset.

✅ The empty set \(\{\}\) (or \(\emptyset\)) has no proper subset.
Q5 What is the difference between \(\{a, b\}\) and \(\{\{a, b\}\}\)?
Solution

The set \(\{a, b\}\) has two elements: \(a\) and \(b\).

The set \(\{\{a, b\}\}\) has only one element, which is itself the set \(\{a, b\}\).

\(\{a, b\}\) — two elements: \(a\), \(b\)
\(\{\{a, b\}\}\) — one element: the set \(\{a, b\}\)
Q6 What is the number of elements of the power set of each of the following sets?
(i) \(\{\}\) (ii) \(\{0, 1\}\) (iii) \(\{1, 2, 3, 4, 5, 6, 7\}\) (iv) \(\{0, 1, 2, 3, 4, 5, 6, 7\}\) (v) \(\{a, \{b, c\}\}\) (vi) \(\{\{a, b\}, \{b, c\}, \{d, e\}\}\)
Solution

If a set has \(n\) elements, its power set has \(2^{n}\) elements.

PartSet\(n\)\(2^{n}\)
(i)\(\{\}\)0\(2^{0} = 1\)
(ii)\(\{0, 1\}\)2\(2^{2} = 4\)
(iii)\(\{1, 2, 3, 4, 5, 6, 7\}\)7\(2^{7} = 128\)
(iv)\(\{0, 1, 2, 3, 4, 5, 6, 7\}\)8\(2^{8} = 256\)
(v)\(\{a, \{b, c\}\}\)2\(2^{2} = 4\)
(vi)\(\{\{a, b\}, \{b, c\}, \{d, e\}\}\)3\(2^{3} = 8\)
Q7 Write down the power set of each of the following sets:
(i) \(\{9, 11\}\) (ii) \(\{+, -, \times, \div\}\) (iii) \(\{\emptyset\}\) (iv) \(\{a, \{b, c\}\}\)
Solution

(i) \(A = \{9, 11\}\)

\(\mathcal{P}(A) = \{\emptyset,\, \{9\},\, \{11\},\, \{9, 11\}\}\)

(ii) \(A = \{+, -, \times, \div\}\)

\(\mathcal{P}(A) = \{\emptyset,\, \{+\},\, \{-\},\, \{\times\},\, \{\div\},\,\)
\(\{+, -\},\, \{+, \times\},\, \{+, \div\},\, \{-, \times\},\, \{-, \div\},\, \{\times, \div\},\,\)
\(\{+, -, \times\},\, \{+, -, \div\},\, \{+, \times, \div\},\, \{-, \times, \div\},\,\)
\(\{+, -, \times, \div\}\}\)

(iii) \(A = \{\emptyset\}\)

\(\mathcal{P}(A) = \{\emptyset,\, \{\emptyset\}\}\)

(iv) \(A = \{a, \{b, c\}\}\)

\(\mathcal{P}(A) = \{\emptyset,\, \{a\},\, \{\{b, c\}\},\, \{a, \{b, c\}\}\}\)

💡 Exam Tip:

When writing sets in set builder notation, first identify the underlying pattern (squares, powers, multiples, divisors, etc.) and then state the domain of the index variable clearly. For power sets, remember the formula \(2^{n}\) where \(n\) is the number of elements in the original set. Always distinguish between an element and a set containing that element — a common exam pitfall in questions like Q5.

❓ Frequently Asked Questions – Exercise 3.1

Recognise the pattern first: these are perfect squares. Since \(484 = 22^{2}\), the general term is \(x = n^{2}\) with \(n\) running from \(1\) to \(22\):

\(\{1, 4, 9, \ldots, 484\} = \{x \mid x = n^{2},\ n \in \mathbb{N} \wedge 1 \leq n \leq 22\}\)

Always identify the underlying pattern and its upper bound before writing the set builder notation.

List every value that satisfies both conditions. The positive multiples of \(3\) that are \(\leq 36\) are:

\(\{3, 6, 9, 12, 15, 18, 21, 24, 27, 30, 33, 36\}\)

A proper subset of a set \(A\) is any subset of \(A\) that is not equal to \(A\) itself.

For \(\{a, b, c\}\), the proper subsets include singletons such as \(\{a\}, \{b\}, \{c\}\), two-element sets such as \(\{a, b\}, \{a, c\}, \{b, c\}\), and the empty set. So \(\{a\}\) and \(\{b\}\) are two valid proper subsets.

The empty set, written as \(\{\}\) or \(\emptyset\), is the only set with no proper subset. Its only subset is itself, so there is no distinct subset smaller than it.

Every non-empty set has at least one proper subset — namely the empty set.

The set \(\{a, b\}\) has two elements: \(a\) and \(b\).

The set \(\{\{a, b\}\}\) has only one element, which itself is the set \(\{a, b\}\).

\(\{a, b\}\) — two elements
\(\{\{a, b\}\}\) — one element (which is a set)

If a set has \(n\) elements, its power set has \(2^{n}\) elements:

\(\{\} \to 2^{0} = 1\)
\(\{0, 1\} \to 2^{2} = 4\)
\(\{1, 2, 3, 4, 5, 6, 7\} \to 2^{7} = 128\)
\(\{0, 1, 2, 3, 4, 5, 6, 7\} \to 2^{8} = 256\)
\(\{a, \{b, c\}\} \to 2^{2} = 4\)
\(\{\{a, b\}, \{b, c\}, \{d, e\}\} \to 2^{3} = 8\)
