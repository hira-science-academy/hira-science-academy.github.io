📌 Important Revision Points

  • Scientific Notation: \(a \times 10^n\) where \(1 \leq a < 10\)
  • Logarithmic Form: If \(a^b = c\), then \(\log_a c = b\)
  • Exponential Form: If \(\log_a c = b\), then \(a^b = c\)
  • Remember: \(\log_a 1 = 0\) and \(\log_a a = 1\)

📐 Review Exercise 2 – Questions & Solutions

Q2 Express the following numbers in scientific notation:
(i) 0.000567 (ii) 734 (iii) \(0.33 \times 10^3\)
Solution
PartNumberScientific Notation
(i)0.000567\(5.67 \times 10^{-4}\)
(ii)734\(7.34 \times 10^2\)
(iii)\(0.33 \times 10^3\)\(3.3 \times 10^{-1} \times 10^3 = 3.3 \times 10^2\)

Q4 Express each of the following in logarithmic form:
(i) \(3^7 = 2187\) (ii) \(a^b = c\) (iii) \(12^2 = 144\)
Solution
PartExponential FormLogarithmic Form
(i)\(3^7 = 2187\)\(\log_3 2187 = 7\)
(ii)\(a^b = c\)\(\log_a c = b\)
(iii)\(12^2 = 144\)\(\log_{12} 144 = 2\)
Q5 Express each of the following in exponential form:
(i) \(\log_4 8 = x\) (ii) \(\log_9 729 = 3\) (iii) \(\log_4 1024 = 5\)
Solution
PartLogarithmic FormExponential Form
(i)\(\log_4 8 = x\)\(4^x = 8\)
(ii)\(\log_9 729 = 3\)\(9^3 = 729\)
(iii)\(\log_4 1024 = 5\)\(4^5 = 1024\)
Q6 Find the value of \(x\) in the following:
(i) \(\log_9 x = 0.5\) (ii) \(\left(\frac{1}{9}\right)^{3x} = 27\) (iii) \(\left(\frac{1}{32}\right)^{2x} = 64\)
Solution

(i) \(\log_9 x = 0.5\)

\(9^{0.5} = x\)
\(9^{\frac{1}{2}} = x\)
\(\sqrt{9} = x\)
\(x = 3\)

(ii) \(\left(\frac{1}{9}\right)^{3x} = 27\)

\((3^{-2})^{3x} = 3^3\)
\(3^{-6x} = 3^3\)
\(-6x = 3\)
\(x = -\frac{1}{2}\)

(iii) \(\left(\frac{1}{32}\right)^{2x} = 64\)

\((2^{-5})^{2x} = 2^6\)
\(2^{-10x} = 2^6\)
\(-10x = 6\)
\(x = -\frac{3}{5}\)
Q7 Write the following as a single logarithm:
(i) \(7\log x - 3\log y^2\) (ii) \(3\log 4 - \log 32\) (iii) \(\frac{1}{3}(\log_5 8 + \log_5 27) - \log_5 3\)
Solution

(i) \(7\log x - 3\log y^2\)

\(= \log x^7 - \log (y^2)^3\)
\(= \log x^7 - \log y^6\)
\(= \log \left(\frac{x^7}{y^6}\right)\)

(ii) \(3\log 4 - \log 32\)

\(= \log 4^3 - \log 32\)
\(= \log 64 - \log 32\)
\(= \log \left(\frac{64}{32}\right)\)
\(= \log 2\)

(iii) \(\frac{1}{3}(\log_5 8 + \log_5 27) - \log_5 3\)

\(= \frac{1}{3}\log_5 (8 \times 27) - \log_5 3\)
\(= \frac{1}{3}\log_5 (216) - \log_5 3\)
\(= \log_5 (216)^{\frac{1}{3}} - \log_5 3\)
\(= \log_5 6 - \log_5 3\)
\(= \log_5 \left(\frac{6}{3}\right)\)
\(= \log_5 2\)
Q8 Expand the following using laws of logarithms:
(i) \(\log(xyz^6)\) (ii) \(\log_3 \sqrt[6]{m^5 n^3}\) (iii) \(\log \sqrt{8x^3}\)
Solution

(i) \(\log(xyz^6)\)

\(= \log x + \log y + \log z^6\)
\(= \log x + \log y + 6\log z\)

(ii) \(\log_3 \sqrt[6]{m^5 n^3}\)

\(= \log_3 (m^5 n^3)^{\frac{1}{6}}\)
\(= \frac{1}{6} \log_3 (m^5 n^3)\)
\(= \frac{1}{6} (\log_3 m^5 + \log_3 n^3)\)
\(= \frac{1}{6} (5\log_3 m + 3\log_3 n)\)

(iii) \(\log \sqrt{8x^3}\)

\(= \log (2^3 x^3)^{\frac{1}{2}}\)
\(= \frac{1}{2} \log (2^3 x^3)\)
\(= \frac{1}{2} (\log 2^3 + \log x^3)\)
\(= \frac{1}{2} (3\log 2 + 3\log x)\)
\(= \frac{3}{2} (\log 2 + \log x)\)
Q9 Find the values of the following with the help of logarithm table:
(i) \(\sqrt[3]{68.24}\) (ii) \(319.8 \times 3.543\) (iii) \(\frac{36.12 \times 750.9}{113.2 \times 9.98}\)
Solution

(i) \(\sqrt[3]{68.24}\)

Let \(x = \sqrt[3]{68.24}\)
\(\log x = \frac{1}{3}\log 68.24\)
\(\log x = \frac{1}{3}(1.8340)\)
\(\log x = 0.6113\)
\(x = \text{Anti log } 0.6113 = 4.086\)

(ii) \(319.8 \times 3.543\)

Let \(x = 319.8 \times 3.543\)
\(\log x = \log 319.8 + \log 3.543\)
\(\log x = 2.5049 + 0.5494\)
\(\log x = 3.0543\)
\(x = \text{Anti log } 3.0543 = 1133\)

(iii) \(\frac{36.12 \times 750.9}{113.2 \times 9.98}\)

Let \(x = \frac{36.12 \times 750.9}{113.2 \times 9.98}\)
\(\log x = \log 36.12 + \log 750.9 - \log 113.2 - \log 9.98\)
\(\log x = 1.5577 + 2.8756 - 2.0538 - 0.9991\)
\(\log x = 1.3804\)
\(x = \text{Anti log } 1.3804 = 24.01\)
Q10 In the year 2016, the population of a city was 22 millions and was growing at a rate of 2.5% per year. The function \(p(t) = 22(1.025)^t\) gives the population in millions, \(t\) years after 2016. Use the model to determine in which year the population will reach 35 millions. Round the answer to the nearest year.
Solution
Given model: \(p(t) = 22(1.025)^t\)
We want \(p(t) = 35\)
\(35 = 22(1.025)^t\)
\(\frac{35}{22} = (1.025)^t\)
\(\log\left(\frac{35}{22}\right) = t \log(1.025)\)
\(\log 35 - \log 22 = t \log 1.025\)
\(1.5441 - 1.3424 = t(0.0107)\)
\(0.2017 = t(0.0107)\)
\(t \approx 18.85 \approx 19 \text{ years}\)
Year = 2016 + 19 = 2035

Always re-read the question to ensure you've answered exactly what was asked (e.g., rounding to the nearest year).
