📌 Formula Summary

  • Range: \(X_{\max} - X_{\min}\).
  • Class size: \(h = \dfrac{\text{Range}}{\text{Number of classes}}\), rounded up.
  • Class boundary: lower boundary \(=\) limit − 0.5; upper boundary \(=\) limit + 0.5.
  • Class mark: \(X = \dfrac{\text{lower boundary} + \text{upper boundary}}{2}\).
  • Mean: \(\bar{X} = \dfrac{\sum X}{n}\) (ungrouped) or \(\dfrac{\sum fX}{\sum f}\) (grouped).
  • Median: middle value in arranged data; for grouped, \(\tilde{X} = \ell + \dfrac{h}{f}\left(\dfrac{n}{2} - c\right)\).
  • Mode: most frequent value; for grouped, \(\hat{X} = \ell + \dfrac{f_m - f_1}{(f_m - f_1) + (f_m - f_2)}\times h\).
  • Weighted mean: \(\bar{X}_w = \dfrac{\sum WX}{\sum W}\).

📒 Chapter 12 – Definitions & Worked Example

D1 What is information?

Knowing about something is called information.

D2 What is data?

The collection of meaningful information as facts and numerical figures is called data.

Note: The term data handling was first used by Sir Ronald Aylmer Fisher (1890–1962), a pioneer in the field of statistics.

D3 Define information handling.

Information handling is the process of collecting, organizing, summarizing, analyzing and interpreting numerical data.

D4 What are the two main types of data?

(i) Discrete data: Can take only specific values; whole numbers are used to represent discrete data. It is obtained only by counting. For example, the number of books sold by a shopkeeper, or the number of patients visiting a hospital in a week.

(ii) Continuous data: Can take every possible value within a given interval; decimal numbers are used to represent continuous data. It is obtained only by measuring. For example, the masses of students in a class (e.g. 28.5 kg, 26.5 kg, 27.5 kg).

D5 What is the difference between ungrouped and grouped data?
Ungrouped dataGrouped data
Data that is not arranged in any systematic order (groups or classes) is called ungrouped data. When data is arranged systematically into classes, it is called grouped data.
It is also known as raw data. Grouped data organizes raw data into intervals for clearer analysis.
Example: 10, 5, 8, 12, 15, 20, 25, 30, … Example: classes 5–9, 10–14, 15–19, … with tally marks and frequencies.
D6 Define class limits.

The minimum and maximum values defined for a class or group are called class limits. The minimum value is called the lower-class limit and the maximum value is called the upper-class limit.

D7 What is a frequency distribution?

A frequency distribution is a table that represents classes or groups along with their respective class frequencies.

D8 What are the steps to construct a frequency distribution?

Step 1 — Calculate the range: the difference between the greatest and smallest value.

\(\text{Range} = X_{\max} - X_{\min}\)

Example: if the greatest value is 136 and the smallest is 30, the range is \(136 - 30 = 106\).

Step 2 — Determine class size: divide the range by the number of classes you wish to make.

\(h = \dfrac{\text{Range}}{\text{Number of classes}} = \dfrac{106}{10} = 10.6 \approx 11\)

Step 3 — Prepare four columns: (i) class limits, (ii) tally marks, (iii) frequencies, (iv) class boundaries.

Step 4 — Make classes using the calculated class size, starting from the smallest value. For example: 30–40, 41–51, 52–62, and so on.

Step 5 — Tally the data: place a tally mark (I) for each data point in its class. Use a diagonal strike on every fifth tally for grouping.

D9 How are class boundaries usually found?

Class boundaries are usually found by the following method:

  1. Choose the upper class limit of the first class and the lower class limit of the second class.
  2. Find the difference between these two limits.
  3. Divide the difference by 2.
  4. Subtract this value from each lower class limit and add it to each upper class limit.

Note: Class boundaries may also be obtained from the midpoints \(x\) using the formula:

\(\text{Class boundaries} = x \pm \dfrac{h}{2}\)

where \(h\) is the difference between any two consecutive values of \(x\).

D11 Define histogram and histogram (unequal class limits).

Histogram: A histogram is a graph of adjacent rectangles constructed on the \(xy\)-plane. It is a graph of a frequency distribution.

Histogram (unequal class limits): A histogram is a graphical representation of a frequency distribution in which rectangles are drawn with widths proportional to the class intervals and heights proportional to the class frequencies. When the widths are unequal, heights represent the adjusted frequency (frequency ÷ width) so the area under each bar equals the frequency.

D12 Define frequency polygon.

A frequency polygon is a closed geometrical figure displaying a frequency distribution. It is drawn by plotting points at (class mark, frequency) and joining them with straight lines, with empty classes closing the shape at both ends.

D13 Define midpoint.

A midpoint is the average value of the lower and upper class limits. It is also known as the class mark and is calculated by:

\(\text{Midpoint} = \dfrac{\text{Lower class limit} + \text{Upper class limit}}{2}\)
D14 What is meant by measure of central tendency?

The measure that gives the centre of the data is called a measure of central tendency. It is used to find the middle or central value of a data set. The measures of central tendency are:

  • (i) Arithmetic mean
  • (ii) Median
  • (iii) Mode
  • (iv) Weighted mean
D15 Define arithmetic mean.

Arithmetic mean (A.M.) is defined as the value of a variable obtained by dividing the sum of all observations by the number of observations. It is denoted by \(\bar{X}\) (read as "X-bar").

Data typeMethodFormula
Ungrouped data Direct \(\bar{X} = \dfrac{\sum X}{n}\)
Shortcut \(\bar{X} = A + \dfrac{\sum D}{n}\), where \(D = X - A\)
Coding \(\bar{X} = A + \dfrac{\sum u}{n}\times h\), where \(u = \dfrac{X - A}{h}\)
Grouped data Direct \(\bar{X} = \dfrac{\sum fX}{\sum f}\), where \(X\) is the class mark
Shortcut \(\bar{X} = A + \dfrac{\sum fD}{\sum f}\), where \(D = X - A\)
Coding \(\bar{X} = A + \dfrac{\sum fu}{\sum f}\times h\), where \(u = \dfrac{X - A}{h}\)
D16 What is median?

Median is the middlemost value in an arranged (ascending or descending order) data set. It divides the data into two equal parts and is denoted by \(\tilde{X}\) (read as "X-tilde").

Case 1 — odd number of observations:

\(\tilde{X} = \left(\dfrac{n+1}{2}\right)^{\text{th}} \text{observation}\)

Case 2 — even number of observations:

\(\tilde{X} = \dfrac{1}{2}\left[\left(\dfrac{n}{2}\right)^{\text{th}} + \left(\dfrac{n}{2}+1\right)^{\text{th}}\right]\) observation
D17 What is mode?

Mode is the value (observation) that appears or occurs most often in a data set. It is the most common value and is denoted by \(\hat{X}\) (read as "X-hat").

Data typeFormula
Ungrouped data Mode = the most frequent observation
Grouped data \(\hat{X} = \ell + \dfrac{f_m - f_1}{(f_m - f_1)+(f_m - f_2)}\times h\)
where \(\ell\) = lower class boundary of modal class, \(h\) = class interval size of modal class, \(f_m\) = frequency of modal class, \(f_1\) = frequency of the class preceding the modal class, \(f_2\) = frequency of the class following the modal class

Note: A data set can have more than one mode if multiple values occur most often. Sometimes a data set has no mode if no value repeats. In a frequency distribution table the exact values are unknown, so we assume the class with the highest frequency is the modal class.

D18 What is weighted mean?

Arithmetic mean is used when all observations are given equal importance or weight. But there are situations in which different observations get different weights. In these situations the weighted mean, denoted by \(\bar{X}_w\), is preferred.

\(\bar{X}_w = \dfrac{\sum WX}{\sum W}\)

💡 Exam Tip:

Learn each definition together with its formula — the definitions section is worth several marks in every board paper, and the formulas are tested in the exercises. Remember the two class-boundary rules: subtract 0.5 from every lower limit and add 0.5 to every upper limit (for integer limits), or use \(x \pm \frac{h}{2}\) when you only have midpoints. When a question asks for the mean, median or mode of grouped data, always show the class marks and the frequency column first — that is where most marks are awarded.

❓ Frequently Asked Questions – Chapter 12 Definitions

Information handling is the process of collecting, organizing, summarizing, analyzing and interpreting numerical data.

Discrete data takes only specific whole-number values and is obtained by counting, for example the number of books sold. Continuous data can take any value within an interval, uses decimals, and is obtained by measuring, for example the mass of a student.

Ungrouped data is raw data that has not been arranged in any systematic order, such as 10, 5, 8, 12. Grouped data has been organized into classes or intervals such as 5–9, 10–14, 15–19, with tally marks and frequencies recorded for each class.

Take the upper class limit of one class and the lower class limit of the next class, divide their difference by 2, then subtract that value from every lower limit and add it to every upper limit. When class limits are integers, this reduces to subtracting 0.5 from each lower limit and adding 0.5 to each upper limit.

Mean: \(\bar{X} = \dfrac{\sum X}{n}\) for ungrouped data, or \(\dfrac{\sum fX}{\sum f}\) for grouped data. Median: the middle value in arranged data, or \(\ell + \dfrac{h}{f}\left(\dfrac{n}{2} - c\right)\) for grouped data. Mode: the most frequent value for ungrouped data, or \(\ell + \dfrac{f_m - f_1}{(f_m - f_1)+(f_m - f_2)}\times h\) for grouped data.
