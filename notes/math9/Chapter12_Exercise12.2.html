📌 Important Revision Points

  • Direct method: \(\bar{X} = \dfrac{\sum fX}{\sum f}\) using midpoints of classes.
  • Short formula: \(\bar{X} = A + \dfrac{\sum fD}{\sum f}\), where \(D = X - A\).
  • Coding method: \(\bar{X} = A + \dfrac{\sum fU}{\sum f}\times h\), where \(U = \dfrac{X - A}{h}\).
  • Median (grouped): \(\tilde{X} = \ell + \dfrac{h}{f}\left(\dfrac{n}{2} - c\right)\).
  • Mode (grouped): \(\hat{X} = \ell + \dfrac{f_m - f_1}{(f_m - f_1) + (f_m - f_2)}\times h\).
  • Weighted mean: \(\bar{X}_w = \dfrac{\sum WX}{\sum W}\).

📐 Exercise 12.2 – Questions & Solutions

Q1 Find the arithmetic mean in each of the following:
(i) 4, 6, 10, 12, 15, 20, 25, 28, 30
(ii) 12, 18, 19, 0, −19, −18, −12
(iii) 6.5, 11, 12.3, 9, 8.1, 16, 18, 20.5, 25
(iv) 8, 10, 12, 14, 16, 20, 22
Solution

(i) 4, 6, 10, 12, 15, 20, 25, 28, 30

\(\sum X = 4 + 6 + 10 + 12 + 15 + 20 + 25 + 28 + 30 = 150,\quad n = 9\)
\(\bar{X} = \dfrac{\sum X}{n} = \dfrac{150}{9} = 16.67\)

(ii) 12, 18, 19, 0, −19, −18, −12

\(\sum X = 12 + 18 + 19 + 0 - 19 - 18 - 12 = 0,\quad n = 7\)
\(\bar{X} = \dfrac{\sum X}{n} = \dfrac{0}{7} = 0\)

(iii) 6.5, 11, 12.3, 9, 8.1, 16, 18, 20.5, 25

\(\sum X = 6.5 + 11 + 12.3 + 9 + 8.1 + 16 + 18 + 20.5 + 25 = 126.4,\quad n = 9\)
\(\bar{X} = \dfrac{126.4}{9} = 14.04\)

(iv) 8, 10, 12, 14, 16, 20, 22

\(\sum X = 8 + 10 + 12 + 14 + 16 + 20 + 22 = 102,\quad n = 7\)
\(\bar{X} = \dfrac{102}{7} = 14.57\)
✅ (i) 16.67    (ii) 0    (iii) 14.04    (iv) 14.57
Q2 Following are the heights in inches of 12 students. Find the median height: 55, 53, 54, 58, 60, 61, 62, 56, 57, 52, 51, 63.
Solution

Arrange in ascending order: 51, 52, 53, 54, 55, 56, 57, 58, 60, 61, 62, 63.

Since \(n = 12\) is even:

\(\tilde{X} = \dfrac{1}{2}\left[\left(\dfrac{n}{2}\right)^{\text{th}} + \left(\dfrac{n}{2}+1\right)^{\text{th}}\right] = \dfrac{1}{2}\left[56 + 57\right] = 56.5\)
✅ Median height = 56.5 inches
Q3 Following are the earnings in Rs. of ten workers: 88, 70, 72, 125, 115, 95, 81, 90, 95, 90. Calculate (i) arithmetic mean, (ii) median, (iii) mode.
Solution

(i) Arithmetic Mean

\(\sum X = 88 + 70 + 72 + 125 + 115 + 95 + 81 + 90 + 95 + 90 = 921,\quad n = 10\)
\(\bar{X} = \dfrac{921}{10} = 92.1\)

(ii) Median

Arrange: 70, 72, 81, 88, 90, 90, 95, 95, 115, 125. Since \(n = 10\),

\(\tilde{X} = \dfrac{1}{2}\left[90 + 90\right] = 90\)

(iii) Mode

Most frequent values: \(90\) (twice) and \(95\) (twice)
✅ Mean = Rs. 92.1    Median = Rs. 90    Mode = Rs. 90 and Rs. 95

Q6 Ten boys working at a petrol pump station receive weekly wages: 4250, 4350, 4400, 4250, 4350, 4410, 4500, 4300, 4500, 4390. Find the arithmetic mean by short formula, the median and the mode.
Solution

Let the assumed mean be \(A = 4350\).

\(\sum D = -100 - 100 - 50 + 0 + 0 + 40 + 60 + 150 + 150 + 40 = 200\)
\(\bar{X} = A + \dfrac{\sum D}{n} = 4350 + \dfrac{200}{10} = 4350 + 20 = 4370\)

Median: arrange in ascending order: 4250, 4250, 4300, 4350, 4350, 4390, 4400, 4410, 4500, 4500.

\(\tilde{X} = \dfrac{1}{2}\left[4350 + 4390\right] = 4370\)

Mode: 4250 (twice), 4350 (twice) and 4500 (twice).

✅ Mean = Rs. 4370    Median = Rs. 4370    Mode = Rs. 4250, 4350 and 4500
Q7 The arithmetic mean of 45 numbers is 80. Find their sum.
Solution
\(\bar{X} = 80,\quad n = 45\)
\(80 = \dfrac{\sum X}{45} \Rightarrow \sum X = 80 \times 45 = 3600\)
✅ Sum = 3600
Q8 Five numbers are 1, 4, 0, 7, 9. Find their mean, median and mode.
Solution
\(\sum X = 1 + 4 + 0 + 7 + 9 = 21,\quad n = 5\)
\(\bar{X} = \dfrac{21}{5} = 4.2\)

Median: arranged data 0, 1, 4, 7, 9; \(n = 5\) (odd).

\(\tilde{X} = \left(\dfrac{5+1}{2}\right)^{3rd} \text{ observation} = 4\)

Mode: no repetition, so no mode.

✅ Mean = 4.2    Median = 4    Mode = none
Q9 A set of data contains the values 148, 145, 160, 157, 156, 160. Show that Mode > Median > Mean.
Solution
\(\sum X = 148 + 145 + 160 + 157 + 156 + 160 = 926,\quad n = 6\)
\(\bar{X} = \dfrac{926}{6} = 154.33\)

Median: arranged data 145, 148, 156, 157, 160, 160.

\(\tilde{X} = \dfrac{156 + 157}{2} = 156.5\)

Mode: 160 occurs twice.

✅ Mode 160 > Median 156.5 > Mean 154.33
Q10 The monthly attendance of 10 students for lunch in the hostel is recorded as 21, 15, 16, 18, 14, 17, 15, 12, 13, 11. Find the median and mode. Also find the mean if \(D = A - 20\).
Solution

Arrange: 11, 12, 13, 14, 15, 15, 16, 17, 18, 21. Median \(= \frac{15+15}{2} = 15\). Mode \(= 15\) (twice).

With assumed mean \(A = 20\):

\(\sum D = -9 - 8 - 7 - 6 - 5 - 5 - 4 - 3 - 2 + 1 = -48\)
\(\bar{X} = A + \dfrac{\sum D}{n} = 20 + \dfrac{-48}{10} = 20 - 4.8 = 15.2\)
✅ Median = 15    Mode = 15    Mean = 15.2

Q12 The arithmetic mean of the ages of 20 boys is 13 years, 4 months and 5 days. Find the sum of their ages. If one boy is exactly 15 years old, what is the average age of the remaining boys?
Solution
\(\bar{X} = 13 + \dfrac{4}{12} + \dfrac{5}{365} \approx 13.374 \text{ years},\quad n = 20\)
\(\sum X = 13.374 \times 20 = 266.94 \text{ years} \approx 266 \text{ years, } 11 \text{ months, } 9 \text{ days}\)

After removing the 15-year-old boy:

\(\sum X = 266.94 - 15 = 251.94,\quad n = 19\)
\(\bar{X} = \dfrac{251.94}{19} \approx 13.26 \text{ years} \approx 13 \text{ years, } 3 \text{ months, } 4 \text{ days}\)
✅ Sum ≈ 266 years 11 months; average of remaining 19 boys ≈ 13 years 3 months
Q13 Calculate the arithmetic mean from the following information:
(i) \(D = X - 140\), \(\sum D = 500\), \(n = 10\)
(ii) \(U = \frac{X - 130}{6}\), \(\sum U = -150\), \(n = 15\)
(iii) \(D = X - 25\), \(\sum fD = 300\), \(\sum f = 20\)
(iv) \(U = \frac{X - 120}{5}\), \(\sum fU = 60\), \(\sum f = 100\)
Solution

(i) \(A = 140\)

\(\bar{X} = 140 + \dfrac{500}{10} = 190\)

(ii) \(A = 130,\; h = 6\)

\(\bar{X} = 130 + \dfrac{-150}{15}\times 6 = 130 - 60 = 70\)

(iii) \(A = 25\)

\(\bar{X} = 25 + \dfrac{300}{20} = 40\)

(iv) \(A = 120,\; h = 5\)

\(\bar{X} = 120 + \dfrac{60}{100}\times 5 = 123\)
✅ (i) 190    (ii) 70    (iii) 40    (iv) 123
Q14 Three children Haris, Maham and Minal made the following scores in a game. Haris: 50, 55, 70, 85, 90. Maham: 75, 60, 60, 45, 53. Minal: 80, 77, 66, 42, 48. The candidate with the highest average score is awarded Rs. 1000. Who will get the award?
Solution
\(\bar{X}_\text{Haris} = \dfrac{350}{5} = 70\)
\(\bar{X}_\text{Maham} = \dfrac{293}{5} = 58.6\)
\(\bar{X}_\text{Minal} = \dfrac{313}{5} = 62.6\)
✅ Haris has the highest average (70) and gets the Rs. 1000 award.

💡 Exam Tip:

Show the assumed mean or coding substitution clearly — most marks are lost at the substitution step, not in the arithmetic. For grouped data, remember that class boundaries (not class limits) are used for median and mode. For the short formula, \(\bar{X} = A + \frac{\sum D}{n}\) is used for ungrouped data, while \(\bar{X} = A + \frac{\sum fD}{\sum f}\) is used for grouped data. Always double-check the weighted mean denominator: it is the sum of weights, not the number of items.
