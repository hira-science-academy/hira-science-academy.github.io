📌 Important Note

Remember that logarithms are the inverse operations of exponentiation. The common logarithm has base 10, while the natural logarithm has base \(e\). Logarithmic properties like product rule, quotient rule, and power rule are essential for solving these problems.

📝 Multiple Choice Questions (PECTAA 2025)

1. The standard form of \(5.2 \times 10^6\) is:

✅ Correct Answer: (C) 5,200,000
\(5.2 \times 10^6 = 5.2 \times 1,000,000 = 5,200,000\).

2. Scientific notation of 0.00034 is:

✅ Correct Answer: (B) \(3.4 \times 10^{-4}\)
Move the decimal point 4 places to the right to get \(3.4\). Since the original number is less than 1, the exponent is negative.

3. The base of common logarithm is:

✅ Correct Answer: (B) 10
Common logarithms (written as \(\log\) or \(\log_{10}\)) have base 10.

4. \(\log_2 2^3 =\)

✅ Correct Answer: (D) 3
\(\log_2 2^3 = 3 \log_2 2 = 3(1) = 3\).

5. \(\log 100 =\)

✅ Correct Answer: (B) 2
\(\log 100 = \log_{10} 10^2 = 2 \log_{10} 10 = 2(1) = 2\).

6. If \(\log 2 = 0.3010\), then \(\log 200\) is:

✅ Correct Answer: (C) 2.3010
\(\log 200 = \log(2 \times 100) = \log 2 + \log 100 = 0.3010 + 2 = 2.3010\).

7. \(\log(0) =\)

✅ Correct Answer: (D) undefined
Logarithm is only defined for positive numbers. \(\log(0)\) is undefined.

8. \(\log 10,000 =\)

✅ Correct Answer: (C) 4
\(\log 10,000 = \log_{10} 10^4 = 4 \log_{10} 10 = 4\).

9. \(\log 5 + \log 3 =\)

✅ Correct Answer: (D) \(\log 15\)
Using the product rule: \(\log 5 + \log 3 = \log(5 \times 3) = \log 15\).

10. \(3^4 = 81\) in logarithmic form is:

✅ Correct Answer: (C) \(\log_3 81 = 4\)
If \(a^b = c\), then \(\log_a c = b\). Here, \(3^4 = 81 \Rightarrow \log_3 81 = 4\).

❓ Frequently Asked Questions – Chapter 2 MCQs

The MCQs on this page test the following ideas: converting between standard and scientific notation, identifying the base of a common logarithm, applying the power rule such as \(\log_2 2^3 = 3\), evaluating common logarithms such as \(\log 100 = 2\), using the product rule \(\log 5 + \log 3 = \log 15\), converting exponential form to logarithmic form, and recognizing that the logarithm of zero is undefined. Each question has a detailed explanation and interactive check-answer feature.

Scientific notation writes a number as \(a \times 10^{n}\), where \(1 \leq a < 10\) and \(n\) is an integer:

Number \(> 1\): move the decimal point left; the count of moves is a positive exponent.
Number \(< 1\): move the decimal point right; the count of moves is a negative exponent.

Examples: \(5.2 \times 10^{6} = 5{,}200{,}000\) and \(0.00034 = 3.4 \times 10^{-4}\).

A common logarithm has base \(10\) and is written as \(\log_{10} x\), or simply \(\log x\) when the base is understood. A natural logarithm has base \(e\) (approximately \(2.718\)) and is written as \(\ln x\).

Common logarithms are used in standard calculations and applications such as the Richter scale, while natural logarithms are used in calculus and growth/decay problems.

Logarithms are only defined for positive arguments. If \(\log 0 = y\), then by definition the base raised to \(y\) would equal \(0\), which is impossible because any positive base raised to any power is always strictly positive:

\(b^{y} > 0\) for all real \(y\) and \(b > 0\), so \(b^{y} = 0\) has no solution.

For the same reason, the logarithm of a negative number is also undefined.

Use the conversion rule:

\(b^{y} = x \;\iff\; \log_b x = y\)

For \(3^{4} = 81\), the base is \(3\), the exponent is \(4\), and the result is \(81\), so the logarithmic form is:

\(3^{4} = 81 \;\iff\; \log_3 81 = 4\)
