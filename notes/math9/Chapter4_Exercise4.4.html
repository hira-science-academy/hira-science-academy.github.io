📌 Important Revision Points

  • Square Root by Factorization: Factorize the polynomial completely. If it's a perfect square, take one factor from each pair.
  • Square Root by Division: Use long division, similar to numerical square roots, until the remainder is zero.
  • Applications: Set the function equal to zero to find break-even points, zero potential energy, or zero deflection.

📐 Exercise 4.4 – Questions & Solutions

Q1 Find the square roots of the following polynomials by factorization method:
(i) \(x^2 - 8x + 16\) (ii) \(9x^2 + 12x + 4\) (iii) \(36a^2 + 84a + 49\) (iv) \(64y^2 - 32y + 4\) (v) \(200t^2 - 120t + 18\) (vi) \(40x^2 + 120x + 90\)
Solution

(i) \(x^2 - 8x + 16\)

\(= (x)^2 - 2(x)(4) + (4)^2\)
\(= (x - 4)^2\)
\(\sqrt{x^2 - 8x + 16} = \sqrt{(x - 4)^2} = \pm(x - 4)\)

(ii) \(9x^2 + 12x + 4\)

\(= (3x)^2 + 2(3x)(2) + (2)^2\)
\(= (3x + 2)^2\)
\(\sqrt{9x^2 + 12x + 4} = \sqrt{(3x + 2)^2} = \pm(3x + 2)\)

(iii) \(36a^2 + 84a + 49\)

\(= (6a)^2 + 2(6a)(7) + (7)^2\)
\(= (6a + 7)^2\)
\(\sqrt{36a^2 + 84a + 49} = \sqrt{(6a + 7)^2} = \pm(6a + 7)\)

(iv) \(64y^2 - 32y + 4\)

\(= (8y)^2 - 2(8y)(2) + (2)^2\)
\(= (8y - 2)^2\)
\(\sqrt{64y^2 - 32y + 4} = \sqrt{(8y - 2)^2} = \pm(8y - 2)\)

(v) \(200t^2 - 120t + 18\)

\(= 2(100t^2 - 60t + 9)\)
\(= 2[(10t)^2 - 2(10t)(3) + (3)^2]\)
\(= 2(10t - 3)^2\)
\(\sqrt{200t^2 - 120t + 18} = \sqrt{2(10t - 3)^2} = \pm\sqrt{2}(10t - 3)\)

(vi) \(40x^2 + 120x + 90\)

\(= 10(4x^2 + 12x + 9)\)
\(= 10[(2x)^2 + 2(2x)(3) + (3)^2]\)
\(= 10(2x + 3)^2\)
\(\sqrt{40x^2 + 120x + 90} = \sqrt{10(2x + 3)^2} = \pm\sqrt{10}(2x + 3)\)
Q2 Find the square root of the following polynomials by division method:
(i) \(4x^4 - 28x^3 + 37x^2 + 42x + 9\)
(ii) \(121x^4 - 198x^3 - 183x^2 + 216x + 144\)
(iii) \(x^4 - 10x^3y + 27x^2y^2 - 10xy^3 + y^4\)
(iv) \(4x^4 - 12x^3 + 37x^2 - 42x + 49\)
Solution

(i) \(4x^4 - 28x^3 + 37x^2 + 42x + 9\)

Square Root \(= \pm(2x^2 - 7x - 3)\)

(ii) \(121x^4 - 198x^3 - 183x^2 + 216x + 144\)

Square Root \(= \pm(11x^2 - 9x - 12)\)

(iii) \(x^4 - 10x^3y + 27x^2y^2 - 10xy^3 + y^4\)

Square Root \(= \pm(x^2 - 5xy + y^2)\)

(iv) \(4x^4 - 12x^3 + 37x^2 - 42x + 49\)

Square Root \(= \pm(2x^2 - 3x + 7)\)
Q3 An investor's return \(R(x)\) in rupees after investing \(x\) thousand rupees is given by quadratic expression: \(R(x) = -x^2 + 6x - 8\). Factorize the expression and find the investment levels that result in zero return.
Solution
\(R(x) = -x^2 + 6x - 8\)
\(R(x) = -[x^2 - 6x + 8]\)
\(R(x) = -[x^2 - 4x - 2x + 8]\)
\(R(x) = -[x(x - 4) - 2(x - 4)]\)
\(R(x) = -(x - 2)(x - 4)\)

To find the investment levels for zero return, set \(R(x) = 0\):

\(-(x - 2)(x - 4) = 0\)
\(x = 2\) or \(x = 4\)
✅ The investment levels that result in zero return are 2 thousand rupees and 4 thousand rupees.
Q4 A company's profit \(P(x)\) in rupees from selling \(x\) units of a product is modeled by the cubic expression: \(P(x) = x^3 - 15x^2 + 75x - 125\). Find the break-even point(s), where the profit is zero.
Solution
\(P(x) = x^3 - 15x^2 + 75x - 125\)
\(P(x) = (x)^3 - 3(x)^2(5) + 3(x)(5)^2 - (5)^3\)
\(P(x) = (x - 5)^3\)

Set \(P(x) = 0\) for break-even point(s):

\((x - 5)^3 = 0 \Rightarrow x - 5 = 0 \Rightarrow x = 5\)
✅ The break-even point is at 5 units.
Q5 The potential energy \(V(x)\) in an electric field varies as a cubic function of distance \(x\), given by: \(V(x) = 2x^3 - 6x^2 + 4x\). Determine where the potential energy is zero.
Solution
\(V(x) = 2x^3 - 6x^2 + 4x\)
\(V(x) = 2x[x^2 - 3x + 2]\)
\(V(x) = 2x[x^2 - 2x - x + 2]\)
\(V(x) = 2x[x(x - 2) - 1(x - 2)]\)
\(V(x) = 2x(x - 2)(x - 1)\)

Set \(V(x) = 0\) for zero potential energy:

\(2x(x - 2)(x - 1) = 0\)
\(x = 0, x = 1, x = 2\)
✅ The potential energy is zero at \(x = 0\), \(x = 1\), and \(x = 2\).
Q6 In structural engineering, the deflection \(Y(x)\) of a beam is given by: \(Y(x) = 2x^2 - 8x + 6\). This equation gives the vertical deflection at any point \(x\) along the beam. Find the points of zero deflection.
Solution
\(Y(x) = 2x^2 - 8x + 6\)
\(Y(x) = 2[x^2 - 4x + 3]\)
\(Y(x) = 2[x^2 - 3x - x + 3]\)
\(Y(x) = 2[x(x - 3) - 1(x - 3)]\)
\(Y(x) = 2(x - 3)(x - 1)\)

Set \(Y(x) = 0\) for points of zero deflection:

\(2(x - 3)(x - 1) = 0\)
Since \(2 \neq 0\), either \(x - 3 = 0\) or \(x - 1 = 0\)
\(x = 3\) or \(x = 1\)
✅ The points of zero deflection are at \(x = 1\) and \(x = 3\).

💡 Exam Tip:

For square roots by factorization, recognize perfect square trinomials like \(a^2 \pm 2ab + b^2 = (a \pm b)^2\). For division method, carefully align terms and subtract step by step. For real-world applications, always set the function equal to zero to find break-even points, zero potential, or zero deflection. Verify your answers by substituting back into the original equation.

❓ Frequently Asked Questions – Exercise 4.4

First, factorize the polynomial completely. If the polynomial is a perfect square, its factors will appear in pairs. The square root is the product of one factor from each pair. For example, \(x^2 - 8x + 16 = (x - 4)^2\), so its square root is \(\pm(x - 4)\).

The division method for square roots is similar to numerical long division. Arrange the polynomial in descending powers. Find the first term of the root by taking the square root of the first term. Then, subtract the square of this term, bring down the next terms, and repeat the process until the remainder is zero. The result is the square root.

The break-even point is the value of \(x\) for which the profit function \(P(x)\) equals zero. This is the point where total revenue equals total cost, meaning the company is neither making a profit nor a loss. For the function \(P(x) = (x - 5)^3\), setting \(P(x) = 0\) gives \(x = 5\), so the break-even point is at 5 units.

To find where a function is zero, set the function equal to zero and solve for the variable. For example, if \(V(x) = 2x^3 - 6x^2 + 4x\), setting \(V(x) = 0\) gives \(2x(x - 2)(x - 1) = 0\). Since 2 is never zero, the solutions are \(x = 0\), \(x = 1\), and \(x = 2\).
