📐 Chapter 1 – Key Definitions & Properties

Def 1 Rational Numbers

A number which can be written in the form \(\frac{p}{q}\), where \(p\) and \(q\) are integers and \(q \neq 0\), is called a rational number. For example: \(\frac{2}{3}, \frac{-5}{7}, 4, 0.25\) etc.

Def 2 Irrational Numbers

A number which cannot be written in the form \(\frac{p}{q}\), where \(p, q\) are integers and \(q \neq 0\), is called an irrational number. For example: \(\sqrt{2}, \sqrt{3}, \pi, e\) etc.

Def 3 Surds and Radicals

An irrational number of the form \(\sqrt[n]{a}\) where \(a\) is a positive rational number and \(n\) is a positive integer greater than 1, is called a surd if it cannot be simplified to a rational number. In \(\sqrt[n]{a}\), \(n\) is called the index, \(a\) is called the radicand, and the symbol \(\sqrt{}\) is called the radical sign.

Def 4 Properties of Equality (Real Numbers)
PropertyAdditionMultiplication
Commutative\(a + b = b + a\)\(ab = ba\)
Associative\(a + (b + c) = (a + b) + c\)\(a(bc) = (ab)c\)
Identity\(a + 0 = a\) (0 is additive identity)\(a \cdot 1 = a\) (1 is multiplicative identity)
Inverse\(a + (-a) = 0\) (-a is additive inverse)\(a \cdot \frac{1}{a} = 1\) (1/a is multiplicative inverse, \(a \neq 0\))
Distributive\(a(b + c) = ab + ac\) and \((a + b)c = ac + bc\)
Def 5 Properties of Inequality (Order Properties)

1. Trichotomy Property: For any real numbers \(a\) and \(b\), one and only one of the following is true: \(a < b\), \(a = b\), or \(a > b\).

2. Transitive Property: If \(a < b\) and \(b < c\), then \(a < c\).

3. Additive Property: If \(a < b\), then \(a + c < b + c\) for any real number \(c\).

4. Multiplicative Property: If \(a < b\) and \(c > 0\), then \(ac < bc\). If \(a < b\) and \(c < 0\), then \(ac > bc\).

💡 Exam Tip:

Definitions are the foundation of your mathematics paper. When asked to define a term, always provide the standard mathematical form (e.g., \(p/q\) for rational numbers) and a simple example. For properties of inequality, pay special attention to the sign reversal when multiplying or dividing by a negative number.
