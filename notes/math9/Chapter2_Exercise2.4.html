📌 Important Laws of Logarithms

  • Product Rule: \(\log_a(mn) = \log_a m + \log_a n\)
  • Quotient Rule: \(\log_a\left(\frac{m}{n}\right) = \log_a m - \log_a n\)
  • Power Rule: \(\log_a(m^n) = n \log_a m\)
  • Change of Base: \(\log_a b = \frac{\log_c b}{\log_c a}\)

📐 Exercise 2.4 – Questions & Solutions

Q1 Without using a calculator, evaluate the following:
(i) \(\log_2 18 - \log_2 9\) (ii) \(\log_2 64 - \log_2 2\) (iii) \(\frac{1}{3}\log_3 8 - \log_3 18\) (iv) \(2\log 2 + \log 25\)
Solution

(i) \(\log_2 18 - \log_2 9\)

\(= \log_2 \left(\frac{18}{9}\right)\)
\(= \log_2 2\)
\(= 1\)

(ii) \(\log_2 64 - \log_2 2\)

\(= \log_2 \left(\frac{64}{2}\right)\)
\(= \log_2 32\)
\(= \log_2 2^5\)
\(= 5 \log_2 2\)
\(= 5(1) = 5\)

(iii) \(\frac{1}{3}\log_3 8 - \log_3 18\)

\(= \log_3 (2^3)^{\frac{1}{3}} - \log_3 (2 \cdot 3^2)\)
\(= \log_3 2 - [\log_3 2 + \log_3 3^2]\)
\(= \log_3 2 - \log_3 2 - 2\log_3 3\)
\(= -2\log_3 3\)
\(= -2(1) = -2\)

(iv) \(2\log 2 + \log 25\)

\(= \log 2^2 + \log 25\)
\(= \log 4 + \log 25\)
\(= \log (4 \times 25)\)
\(= \log 100\)
\(= \log_{10} 10^2 = 2\)
Q2 Write the following as a single logarithm:
(i) \(\frac{1}{2}\log 25 - 2\log 3\) (ii) \(\log 9 - \log \frac{1}{3}\) (iii) \(\log_5 b^2 \cdot \log_a 5^3\) (iv) \(2\log_3 x + \log_3 y\) (v) \(4\log_5 x - \log_5 y + \log_5 z\) (vi) \(2\ln a + 3\ln b - 4\ln c\)
Solution

(i) \(\frac{1}{2}\log 25 - 2\log 3\)

\(= \log (5^2)^{\frac{1}{2}} - \log 3^2\)
\(= \log 5 - \log 9\)
\(= \log \left(\frac{5}{9}\right)\)

(ii) \(\log 9 - \log \frac{1}{3}\)

\(= \log \left(\frac{9}{1/3}\right)\)
\(= \log (9 \times 3)\)
\(= \log 27\)

(iii) \(\log_5 b^2 \cdot \log_a 5^3\)

\(= 2\log_5 b \cdot 3\log_a 5\)
\(= 6 \log_5 b \cdot \log_a 5\)
\(= 6 \left(\frac{\log b}{\log 5}\right) \left(\frac{\log 5}{\log a}\right)\)
\(= 6 \left(\frac{\log b}{\log a}\right)\)
\(= 6 \log_a b\)

(iv) \(2\log_3 x + \log_3 y\)

\(= \log_3 x^2 + \log_3 y\)
\(= \log_3 (x^2 y)\)

(v) \(4\log_5 x - \log_5 y + \log_5 z\)

\(= \log_5 x^4 - \log_5 y + \log_5 z\)
\(= \log_5 \left(\frac{x^4 z}{y}\right)\)

(vi) \(2\ln a + 3\ln b - 4\ln c\)

\(= \ln a^2 + \ln b^3 - \ln c^4\)
\(= \ln \left(\frac{a^2 b^3}{c^4}\right)\)
Q3 Expand the following using laws of logarithms:
(i) \(\log\left(\frac{11}{5}\right)\) (ii) \(\log_5 \sqrt{8a^6}\) (iii) \(\ln\left(\frac{a^2 b}{c}\right)\) (iv) \(\log\left(\frac{xy}{z}\right)^{\frac{1}{9}}\) (v) \(\ln \sqrt[3]{16x^3}\) (vi) \(\log_2\left(\frac{1-a}{b}\right)^5\)
Solution

(i) \(\log\left(\frac{11}{5}\right)\)

\(= \log 11 - \log 5\)

(ii) \(\log_5 \sqrt{8a^6}\)

\(= \log_5 (8a^6)^{\frac{1}{2}}\)
\(= \frac{1}{2} \log_5 (8a^6)\)
\(= \frac{1}{2} [\log_5 8 + \log_5 a^6]\)
\(= \frac{1}{2} [\log_5 8 + 6\log_5 a]\)

(iii) \(\ln\left(\frac{a^2 b}{c}\right)\)

\(= \ln a^2 + \ln b - \ln c\)
\(= 2\ln a + \ln b - \ln c\)

(iv) \(\log\left(\frac{xy}{z}\right)^{\frac{1}{9}}\)

\(= \frac{1}{9} \log\left(\frac{xy}{z}\right)\)
\(= \frac{1}{9} [\log x + \log y - \log z]\)

(v) \(\ln \sqrt[3]{16x^3}\)

\(= \ln (16x^3)^{\frac{1}{3}}\)
\(= \frac{1}{3} \ln (16x^3)\)
\(= \frac{1}{3} [\ln 16 + \ln x^3]\)
\(= \frac{1}{3} [\ln 2^4 + 3\ln x]\)
\(= \frac{1}{3} [4\ln 2 + 3\ln x]\)
\(= \frac{4}{3}\ln 2 + \ln x\)

(vi) \(\log_2\left(\frac{1-a}{b}\right)^5\)

\(= 5 \log_2\left(\frac{1-a}{b}\right)\)
\(= 5[\log_2(1-a) - \log_2 b]\)
Q4 Find the value of \(x\) in the following equations:
(i) \(\log 2 + \log x = 1\) (ii) \(\log_2 x + \log_2 8 = 5\) (iii) \((81)^x = (243)^{x+2}\) (iv) \(\left(\frac{1}{27}\right)^{x-6} = 27\) (v) \(\log(5x - 10) = 2\) (vi) \(\log_2(x + 1) - \log_2(x - 4) = 2\)
Solution

(i) \(\log 2 + \log x = 1\)

\(\log (2x) = 1\)
\(10^1 = 2x\)
\(10 = 2x\)
\(x = 5\)

(ii) \(\log_2 x + \log_2 8 = 5\)

\(\log_2 (8x) = 5\)
\(2^5 = 8x\)
\(32 = 8x\)
\(x = 4\)

(iii) \((81)^x = (243)^{x+2}\)

\((3^4)^x = (3^5)^{x+2}\)
\(3^{4x} = 3^{5x+10}\)
\(4x = 5x + 10\)
\(-x = 10 \Rightarrow x = -10\)

(iv) \(\left(\frac{1}{27}\right)^{x-6} = 27\)

\((27^{-1})^{x-6} = 27^1\)
\(27^{-x+6} = 27^1\)
\(-x + 6 = 1\)
\(-x = -5 \Rightarrow x = 5\)

(v) \(\log(5x - 10) = 2\)

\(10^2 = 5x - 10\)
\(100 = 5x - 10\)
\(110 = 5x\)
\(x = 22\)

(vi) \(\log_2(x + 1) - \log_2(x - 4) = 2\)

\(\log_2\left(\frac{x+1}{x-4}\right) = 2\)
\(2^2 = \frac{x+1}{x-4}\)
\(4 = \frac{x+1}{x-4}\)
\(4(x - 4) = x + 1\)
\(4x - 16 = x + 1\)
\(3x = 17 \Rightarrow x = \frac{17}{3}\)
Q5 Find the values of the following with the help of logarithm table:
(i) \(\frac{3.68 \times 4.21}{5.234}\) (ii) \(4.67 \times 2.11 \times 2.397\) (iii) \(\frac{(20.46)^2 \times (2.4122)}{754.3}\) (iv) \(\frac{\sqrt[3]{9.364} \times 21.64}{3.21}\)
Solution

(i) \(\frac{3.68 \times 4.21}{5.234}\)

Let \(x = \frac{3.68 \times 4.21}{5.234}\)
\(\log x = \log 3.68 + \log 4.21 - \log 5.234\)
\(\log x = 0.5658 + 0.6243 - 0.7188\)
\(\log x = 0.4713\)
\(x = \text{Anti log } 0.4713 = 2.960\)

(ii) \(4.67 \times 2.11 \times 2.397\)

Let \(x = 4.67 \times 2.11 \times 2.397\)
\(\log x = \log 4.67 + \log 2.11 + \log 2.397\)
\(\log x = 0.6693 + 0.3243 + 0.3797\)
\(\log x = 1.3733\)
\(x = \text{Anti log } 1.3733 = 23.62\)

(iii) \(\frac{(20.46)^2 \times (2.4122)}{754.3}\)

Let \(x = \frac{(20.46)^2 \times (2.4122)}{754.3}\)
\(\log x = 2\log 20.46 + \log 2.4122 - \log 754.3\)
\(\log x = 2(1.3109) + 0.3824 - 2.8775\)
\(\log x = 2.6218 + 0.3824 - 2.8775\)
\(\log x = 0.1267\)
\(x = \text{Anti log } 0.1267 = 1.338\)

(iv) \(\frac{\sqrt[3]{9.364} \times 21.64}{3.21}\)

Let \(x = \frac{\sqrt[3]{9.364} \times 21.64}{3.21}\)
\(\log x = \frac{1}{3}\log 9.364 + \log 21.64 - \log 3.21\)
\(\log x = \frac{1}{3}(0.9715) + 1.335 - 0.5065\)
\(\log x = 0.3238 + 1.335 - 0.5065\)
\(\log x = 1.1523\)
\(x = \text{Anti log } 1.1523 = 14.20\)
Q6 The formula to measure the magnitude of earthquakes is given by \(M = \log_{10} \left(\frac{A}{A_0}\right)\). If amplitude \(A\) is 10,000 and reference amplitude \(A_0\) is 10, what is the magnitude of the earthquake?
Solution
\(M = \log_{10} \left(\frac{A}{A_0}\right)\)
Put \(A = 10000\) and \(A_0 = 10\)
\(M = \log_{10} \left(\frac{10000}{10}\right)\)
\(M = \log_{10} (1000)\)
\(M = \log_{10} (10^3)\)
\(M = 3\log_{10} 10 = 3(1) = 3\)
Q7 Abdullah invested Rs. 100,000 in a saving scheme and gains interest at the rate of 5% per annum so that the total value of this investment after \(t\) years is Rs \(y\). This is modelled by an equation \(y = 1,00,000(1.05)^t\), \(t \geq 0\). Find after how many years the investment will be doubled?
Solution
Initial investment = Rs. 100,000
Double the investment: \(y = 200,000\)
\(200,000 = 100,000(1.05)^t\)
\(2 = (1.05)^t\)
\(\log 2 = t \log 1.05\)
\(t = \frac{\log 2}{\log 1.05} = \frac{0.3010}{0.0212} \approx 14.2\) years
Q8 Huria is hiking up a mountain where the temperature \((T)\) decreases by 3% (or a factor of 0.97) for every 100 meters gained in altitude. The initial temperature \((T_i)\) at sea level is \(20^\circ C\). Using the formula \(T = T_i \times 0.97^{h/100}\), calculate the temperature at an altitude \((h)\) of 500 meters.
Solution
\(T = T_i \times 0.97^{h/100}\)
Put \(T_i = 20\) and \(h = 500\)
\(T = 20 \times 0.97^{500/100}\)
\(T = 20 \times 0.97^5\)
\(\log T = \log 20 + 5\log 0.97\)
\(\log T = 1.3010 + 5(-0.0132)\)
\(\log T = 1.3010 - 0.066\)
\(\log T = 1.235\)
\(T = \text{Anti log } 1.235 = 17.18^\circ C\)

💡 Exam Tip:

Remember that when you have a logarithmic equation like \(\log_2(x+1) - \log_2(x-4) = 2\), you should first combine the logs into a single logarithm, then convert to exponential form. Also, always check that the argument of the logarithm is positive (i.e., \(x > 4\) in this case) to avoid extraneous solutions.

❓ Frequently Asked Questions – Exercise 2.4

The three main laws are:

Product: \(\log_a(mn) = \log_a m + \log_a n\)
Quotient: \(\log_a\!\left(\frac{m}{n}\right) = \log_a m - \log_a n\)
Power: \(\log_a(m^n) = n \log_a m\)

Together with the change-of-base formula they cover every transformation used in this exercise.

Apply the quotient rule directly:

\(\log_2 18 - \log_2 9 = \log_2\!\left(\frac{18}{9}\right) = \log_2 2 = 1\)

Apply the power rule first, then the product rule:

\(2\log 2 = \log(2^2) = \log 4\)
\(\log 4 + \log 25 = \log(4 \times 25) = \log 100\)

Since the base is \(10\), \(\log 100 = 2\).

Combine and convert to exponential form:

\(\log_2\!\left(\frac{x+1}{x-4}\right) = 2\)
\(\frac{x+1}{x-4} = 2^2 = 4\)
\(x + 1 = 4x - 16\)
\(3x = 17 \;\Rightarrow\; x = \frac{17}{3}\)

Always check the original arguments are positive: \(x+1 > 0\) and \(x-4 > 0\), so \(x > 4\). Since \(\frac{17}{3} \approx 5.67 > 4\), the solution is valid.

The Richter scale formula is:

\(M = \log_{10}\!\left(\frac{A}{A_0}\right)\)

Substitute \(A = 10{,}000\) and \(A_0 = 10\):

\(M = \log_{10}(1000) = \log_{10}(10^3) = 3\)

So the earthquake has magnitude \(3\) on the Richter scale.
