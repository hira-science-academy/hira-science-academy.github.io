📌 Important Revision Points

  • Class size (inclusive): \(h = \text{upper limit} - \text{lower limit} + 1\).
  • Class boundary: lower boundary = limit − 0.5; upper boundary = limit + 0.5.
  • Class mark: \(X = \dfrac{\text{lower boundary} + \text{upper boundary}}{2}\).
  • Adjusted frequency: \(f / w\) when class widths are unequal.
  • Mean: \(\bar{X} = \dfrac{\sum X}{n}\) (ungrouped) or \(\bar{X} = \dfrac{\sum fX}{\sum f}\) (grouped).
  • Short formula: \(\bar{X} = A + \dfrac{\sum fD}{\sum f}\) where \(D = X - A\).
  • Median: middle value in an ordered list; for even \(n\), average of the two middle values.
  • Mode: the value that appears most often.

📐 Review Exercise 12 – Questions & Solutions

Q2 Define the following: (i) frequency distribution (ii) histogram (unequal class limits) (iii) mean (iv) median.
Solution

(i) Frequency distribution

A frequency distribution is a table that represents classes or groups along with their respective class frequencies.

(ii) Histogram (unequal class limits)

A histogram is a graphical representation of a frequency distribution in which rectangles are drawn with widths proportional to the class intervals and heights proportional to the class frequencies. When class widths are unequal, the height is the adjusted frequency (frequency ÷ width).

(iii) Mean

The arithmetic mean (A.M.) or mean of a variable is obtained by dividing the sum of all observations by the number of observations. For \(x_1, x_2, \ldots, x_n\):

\(\bar{X} = \dfrac{x_1 + x_2 + \cdots + x_n}{n} = \dfrac{\sum X}{n}\)

(iv) Median

The median is the middlemost value in an arranged (ascending or descending order) data set. It divides the data into two equal parts and is denoted by \(\tilde{X}\).

✅ All four definitions stated and matched to the textbook wording.

Q11 Usman rolled a fair dice eight times. Each time their sum was recorded as 8, 5, 6, 6, 9, 4, 3, 11. Find the median and mode of the sum.
Solution

Arrange in ascending order: 3, 4, 5, 6, 6, 8, 9, 11.

Since \(n = 8\) (even):

\(\tilde{X} = \dfrac{1}{2}\left[6 + 6\right] = 6\)

Mode: the most frequent observation is 6 (appears twice; every other value once).

✅ Median = 6    Mode = 6

💡 Exam Tip:

In a review exercise the marks come from showing the method, not from the final number. Always write the class boundaries in a column before drawing any graph, use adjusted frequency (frequency ÷ width) whenever class widths differ, and show the assumed mean or coding substitution explicitly for the short method. For the median and mode, arrange the data in order first — that single step is worth marks on its own. When asked to give a definition, copy the textbook wording closely and add one worked example to make it concrete.

Class limits are the written ends of a class interval, such as 20–24. Class boundaries close the gap between consecutive intervals by adding 0.5 to the upper limit and subtracting 0.5 from the lower limit, giving 19.5–24.5. Histograms use class boundaries, not class limits.

When classes have unequal widths, the height of each bar must represent frequency density (also called adjusted frequency), computed as frequency divided by class width, so the area under each bar equals the frequency. Question 4 of this review exercise is a direct example of this rule.
